## 4. 附录

### 4.1 字段说明

| 字段 | 含义 |
|---|---|
| `roomType` | 舱室类型枚举（见 §1.2） |
| `stationMaxCount` | 舱内工位数上限（工位下标，不是舱室数量） |
| `machineCapacity` | 制造舱生产载荷（设定生产数量占用，超限不可设） |
| `unlockPlantingField` | 培养舱本级解锁的培养位编号（1–9） |
| `totalProgress` | 配方完成所需进度值 |
| `perCapacity` | 制造配方单次生产占用的载荷 |
| `slot` | 干员技能槽（每名干员 2 槽） |
| `level`（技能） | 技能档位 1/2，对应后缀 α/β 或 β/γ |
| `effect.rate` | 效果倍率，0.2 = 20% |
| `conditionType=5022` | 条件为「总控中枢达到 N 级」，参数即 N |
| `conditionType=2147483647` | 无条件（建造/剧情解锁） |

### 4.2 未纳入本文档的相邻数据

- 线索 / 信赖 / 送礼衰减 / 会客室展示位：可另行补充（分组 H）
- `SpaceshipConst` 全局常量约 50 项（分组 I）
- 干员舱内行为、迎接语音 id、proxy 模型 id（分组 F）
- 餐厅系统 `Inn*`（按确认不纳入）
