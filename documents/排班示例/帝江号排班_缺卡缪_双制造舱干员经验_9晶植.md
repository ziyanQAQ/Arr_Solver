## 1. 缺卡缪之后，池子到底少了什么

先把「谁在哪条属性上有多少点」结算清楚。这一步决定后面所有枚举的边界。

### 1.1 干员经验（`A3+D1`，effectType=7 参数2=1）

| 干员 | 加成 `b` | 制造舱心情减免 `r` | 备注 |
|---|---|---|---|
| 莱万汀 | **+30%** | **18%** | 双槽都在制造舱（D1 + B2），占用代价 0 |
| 庄方宜 | **+30%** | **18%** | 同上 |
| 余烬 | **+30%** | 0 | 另一槽是 C2d（线索概率），与产出无关 |
| 噗切娜 | **+30%** | 0 | 另一槽是 C2b |
| 狼卫 | +20% | 0 | 另一槽是 A4+E2（矿物），本方案不用 |
| 赛希 | +20% | 0 | β 封顶（标准化编译 20%），另一槽是 C2e |
| ~~卡缪~~ | ~~+30%~~ | ~~0~~ | **缺失** |

**结算**：`Σb = 30×4 + 20×2 = 160%`；`Σr = 18 + 18 = 36%`。30% 档从 **5 人降到 4 人**。

另外可作「纯心情位」的制造舱干员（干员经验加成 0）：洁尔佩塔 18%、骏卫 18%、秋栗 14%、昼雪 14%。

> **关键后果**：`b=90%` 必须由三个 30% 位凑满，而 30% 档只剩 4 人 ⇒ 12 个班次位（2 舱 × 2 班 × 3 工位）里，**最多只有一个班次能拿 90%**；另一个班次最高只能是 70%（30+20+20）。这正是「不能简单把卡缪换成余烬」的原因（见 §11.3）。

### 1.2 晶植（`A4+E1`，effectType=3 参数2=2）

别礼 +30%、汤汤 +30%（且 18% 心情）、诀 +30%、~~卡缪 +30%（缺失）~~。

**结算**：30% 档剩 **3 人，恰好等于 90% 所需人数**。但要一次拿满 90% 就必须把这 3 人全放进同一班 ⇒ B 班晶植加成必然为 0。（即使有卡缪，主逻辑 §6.10 的答案也是把 3 人放 A 班、卡缪去制造舱，所以**培养舱的产出与缺卡缪无关**——§6 会算出这一点。）

### 1.3 会客室与中枢（不受影响）

- 线索收集 `A2+C1` 30% 档 4 人：洛茜、艾尔黛拉、祀、埃特拉（⇐ 恰够 90% + 30%）。
- 会客室心情 `A2+B2` 18%：洛茜、艾尔黛拉、祀、梨诺、秋栗（洛茜/艾尔黛拉/祀 三人合计 54%；梨诺在中枢，B 班用秋栗凑 18%，够用即可）。
- 中枢恢复：16% 档 5 人（黎风、梨诺、大潘、萤石、昼雪），12% 档 5 人（佩丽卡、艾维文娜、卡契尔、埃特拉、阿列什）。

### 1.4 全船可用人数

32 名干员 − 卡缪 = **31 人**。本方案占用 28 人，空余 3 人（艾维文娜、佩丽卡、弧光）。

## 2. 算法骨架（照主逻辑 §6.4 走）

```
① 外层：枚举中枢配置 C0 = (h_中枢, A组, B组) → 得到唯一时间轴 u(t)
② 内层：按类别排，类别顺序 = 线索 ≻ 干员经验 ≻ 武器经验 ≻ 培养产物
        · 同一类别的多个设施【联合枚举】（干员经验 → 制造1 + 制造2 一起分配人员）
        · 任何班次 R < C ⇒ 淘汰该分支（或按 §4.4/§6.7 降级后比较）
④ 所有中枢配置比完，取字典序最高的一组
```

**本方案必须按这个顺序做的三个理由**（照抄 §6.1/§6.2 的理由，用在本题上）：

1. 中枢是**唯一影响全船**的量：`u` 一掉，所有 A 班一起掉 ⇒ 必须先定时间轴；
2. 线索是最高优先级 ⇒ 会客室先吃满，再谈制造舱；卡缪缺失不影响会客室，所以**会客室的结论可以直接复用 §6.10 的 20/4**（但下文仍独立复核一遍）；
3. 干员经验是两个舱的**合计**，不是逐个舱 ⇒ 必须联合分配人员（本方案的最优解恰好就是「联合分配才拿得到」的那种，见 §4.4）。

### 2.1 这一节先把「四条硬边界」摆出来（后面每个候选都要过）

| # | 边界 | 式子 |
|---|---|---|
| B1 | 有效时长被心情上限截断 | `H = min(h, 1/d)` |
| B2 | 两班互补 | `h_B = 24 − h_A`，且 `h_A ∈ 1..23` 整数 |
| B3 | A 班稳定 ⇒ 休息窗够回 | `R = v·(24 − h) ≥ C = min(1, d·h)`，`v = 0.1776` |
| B4 | 人员唯一 + 每班 ≥1 人 | 全船同一人只上一个班次 |

**由 B3 立刻得到一个极好用的「班长上限」**（本方案休息窗全在中枢 B 段，`v = 17.76%`）：

```
0.1776 × (24 − h) ≥ d·h   ⇒   h ≤ 4.2624 / (0.1776 + d)
```

| `r` | `d = 0.072(1−r)` | `1/d` | 班长上限 `4.2624/(0.1776+d)` | **B1 与 B3 共同给出的 `H` 上限** |
|---|---|---|---|---|
| 0% | 7.200% | 13.8889 | 17.0769 | **13.8889**（B1 更紧） |
| 14% | 6.192% | 16.1499 | 17.7953 | **16.1499**（B1） |
| 18% | 5.904% | **16.9377** | 18.0123 | **16.9377**（B1） |
| 28% | 5.184% | 19.2901 | 18.5773 | **18.0000**（B3 更紧 → 整数 18） |
| 32% | 4.896% | 20.4248 | 18.8136 | **18.0000**（B3） |
| 36% | 4.608% | 21.7014 | 19.0559 | **19.0000**（B3） |
| 50% | 3.600% | 27.7778 | 19.9551 | **19.0000**（B3） |
| 54% | 3.312% | 30.1932 | 20.2278 | **20.0000**（B3） |

**读法**：`r` 越高，`1/d` 和 B3 上限都变大，所以 `H` 上限随 `r` 单调上升。这就是「用心情干员换班长」的全部经济来源。

## 3. 中枢（时间轴）：先把 `u(t)` 定下来

中枢本身无产出（`base*ProduceRate` 不作用于中枢，且中枢只认 `A1+B1` 恢复技能）⇒ 它是**成本项**：人数越少越好、机会成本越低越好（主逻辑 §6.6）。

### 3.1 中枢强度需求的算法

按 §6.6，中枢强度不是固定值，而是**由各设施班长倒推**：

```
某段需要的平均回复 = C / 休息小时 = (d × h) / (24 − h)
该段需要的 u       = 需要的平均回复 / 0.12 − 1
```

中枢可用档位只有 **16% / 12%**（最高档），一段最多 3 人 ⇒ 单段 `u` 的可行取值只有
`0, 12, 16, 24, 28, 32, 36, 40, 44, 48`（%），**上限 48%**（16×3）。

### 3.2 会客室先算（优先级①）

会客室 `A2+C1` 30% 档 4 人，所以两班的加成上限是 **90% / 30%**：

- A 组取 3 人（洛茜 + 艾尔黛拉 + 祀）：收集 `+90%`，心情减免 `18×3 = 54%`
  → 倍率 `E_A = (1 + 0.40×3) × (1 + 0.90) = 2.2 × 1.90 = 4.18`
  → `d_A = 0.072 × (1 − 0.54) = 3.312%`，`1/d_A = 30.1932`
- B 组取剩下的 1 人（埃特拉 `+30%`）+ 2 名纯心情位（秋栗 18%；第 3 人随便，`H` 反正被 `h_B` 截断）
  → `E_B = 2.2 × 1.30 = 2.86`，`d_B = 0.072 × (1−0.18) = 5.904%`（若第 3 位也带心情则更低，但 `h_B ≤ 10 < 1/d_B` 恒成立，**对产量无影响**）

**A 班班长上限**（B3，会客室 A 班休息窗落在中枢 B 段）：

```
h ≤ 4.2624 / (0.1776 + 0.03312) = 4.2624 / 0.21072 = 20.2278  ⇒ 整数 h ≤ 20
```

**单舱价值函数**（`h_B = 24 − h ≤ 21.70`，B 班永远满时长）：

```
V(h) = 4.18 × min(h, 30.1932) + 2.86 × (24 − h)
```

在 `h ≤ 20` 区间内 `V` 对 `h` 单调递增（因为 `4.18 > 2.86`）⇒ **取最大的可行 h = 20**：

```
Y_A = 4.18 × 20 = 83.60
Y_B = 2.86 × 4  = 11.44
Y_日 = 95.04 等效小时          （→ 95.04 / 24.4444 = 3.888 张/日）
```

**反证 `h = 21` 不可行**：`C = 3.312% × 21 = 69.552%`，休息窗只有 3 h，即使把中枢顶到满 48%
也只有 `3 × 17.76% = 53.28% < 69.552%` ✘ ⇒ `h = 20` 是硬上限。
**再证 `h = 19` 更差**：`4.18×19 + 2.86×5 = 79.42 + 14.30 = 93.72 < 95.04` ✘。

⇒ **会客室锁定 20/4，95.04**（与主逻辑 §6.10 一致）。

### 3.3 会客室反过来给中枢提出的硬指标

- A 班（20 h）休息窗 = `[20, 24]`，`C = 0.6624`
  ⇒ 这 4 h 内 `v ≥ 0.6624 / 4 = 16.56%` ⇒ `u ≥ 16.56/12 − 1 = 38.0%`。
- 中枢单段最多 3 人：2 人上限 `32%` → `v = 15.84%` → `R = 63.36% < 66.24%` ✘
  ⇒ **中枢 B 段必须 3 人**，取值 `40% / 44% / 48%` 都可（48% 的三人正好是 §6.6 列的三名「零机会成本」16% 档）。

### 3.4 定案

```
中枢：h = 14，A 组 = 阿列什（12%），B 组 = 黎风 + 梨诺 + 大潘（16×3 = 48%）
⇒ u(t) = 12% 于 [0,14)，48% 于 [14,24]
⇒ v(t) = 13.44%/h 于 [0,14)，17.76%/h 于 [14,24]
```

**为什么 `h = 14` 够用**：本方案四个设施最长的那一档 A 班结束于 **17:00**（制造 1/2、培养舱），会客室结束于 20:00。
`14 ≤ 17` ⇒ **全部 A 班休息窗都整段落在中枢 B 段内**，一律吃 `v = 17.76%`，不需要分段累加。

- 中枢 A 段（阿列什，14 h）：`C = min(1, 7.2%×14) = 1.0000`；连续在岗上限 `13.889 h` ⇒ **13:53:20 红脸**，`[13:53:20, 14:00)` 这一段 `u = 0`。空窗是否可接受，按 §6.6 判据在 §9.5 校验（结论：可接受）。
- 中枢 B 段（3 人，10 h）：`C = 0.72`，休息窗 `[0,14]`，`t满 = 0.72/0.1344 = 5.357 h ≪ 14` ✔ 且 10 h < 13.889 h ⇒ B 段全程无红脸，`u = 48%` 稳定输出。

> **中枢强度的说明（不影响任何产量）**：`40%`（黎风 + 两名 12%）与 `44%`、`48%` 都能让会客室回满，产量完全相同。
> 按 §6.6「①人数最少 → ②机会成本最低」，48% 这一档用的是三个人**在别处都无效率价值**的 16% 档（黎风 = 线索概率、梨诺 = 会客心情（本方案 B 班用不上）、大潘 = 菌类（本方案 9 槽全晶植）），
> 而 40% 要拉进佩丽卡（武器 30%，主逻辑 §6.6 列为「高成本」）。所以本方案取 48%，并额外获得 16 分 13 秒的余量。§9.6 会把三个取值一起验算一遍。

## 4. 干员经验（优先级②）：两舱联合枚举

这是本题**唯一需要真枚举**的类别，也是缺卡缪真正改变结果的地方。

### 4.1 单舱价值函数

一个舱 = A 班 `(b_A, r_A, h)` + B 班 `(b_B, r_B, 24−h)`：

```
E = 2.2 × (1 + b)
d = 0.072 × (1 − r)
H_A = min(h, 1/d_A)       且 h ≤ ⌊4.2624/(0.1776 + d_A)⌋      —— 见 §2.1 表
H_B = 24 − h              （24−h ≤ 10 < 1/d_B 恒成立 ⇒ B 班永远不被心情截断）
V_舱(h) = E_A·H_A + E_B·H_B
```

因为 `E_A > E_B` 在所有候选里都成立（B 班最多剩 70%，A 班至少 30%…实际枚举里 A 班都 ≥50%），
**`V_舱` 对 `h` 单调递增**，所以每个舱的最优班长就是

```
h* = min( ⌈1/d_A⌉ , ⌊4.2624/(0.1776+d_A)⌋ )
```

——「`⌈1/d_A⌉`」的含义：班长超过 `1/d_A` 之后 `H` 不再增长，只会白砍 B 班的时长，所以**只要把 A 班排到刚好覆盖 `1/d_A` 的整数小时**。

## 11. 与「满配含卡缪」方案的差异，以及为什么不能简单替换

### 11.1 主逻辑 §6.10 的答案（含卡缪）


### 11.2 缺卡缪后的最优（本方案）

```

干员经验合计 = 164.946
```

### 11.3 三条差异的解释

1. **不是「卡缪 → 余烬」就完事**。
   §6.10 的结构需要同时成立两件事：舱甲拿 `90% + 36%`（必须吃掉莱万汀、庄方宜、余烬三人），舱乙拿 `80%`（卡缪 30 + 噗切娜 30 + 狼卫 20）。
   卡缪一缺，舱乙只剩 `70%`（噗切娜 30 + 狼卫 20 + 赛希 20）；如果硬把余烬让给舱乙，舱甲就掉到 `60% + 36%`（`E=3.52`）。
   两条路我都算了：

   ```
   硬替换（余烬去舱乙）：舱甲 {L,Z,白} (60,36) h=19 = 77.880；舱乙 {Y,P,W} (80,0) h=14 = 77.000；赛希进 10 h B 班 +4.400
                       合计 = 77.880 + 77.000 + 4.400 = 159.280   ← 比 164.946 低 5.67
   换结构（本方案）    ：两舱都做 r=18% 的 17/7                                = 164.946
   ```

2. **整条时间轴跟着变**：`r=36%` 那一段能撑 19 h，`r=18%` 只能撑 16.9377 h。缺一个 30% 档干员，等于把「一舱 19/5 + 一舱 14/10」换成「两舱都 17/7」——B 班总时长从 15 h 变成 14 h，A 班总有效时长从 `19+13.889` 变成 `2×16.9377`。
   算总账：`171.82 − 164.946 = 6.874`（−4.00%）。

3. **培养舱与会客室不受影响**（§6.3 已验算 775.795 与 95.04 都没变）。方向性结论：**卡缪的价值全在制造舱（30% 干员经验），不在培养舱**——培养舱的 90% 由另外 3 人就能凑满。
