## 1. 计算口径与符号

### 1.1 口径〔原文〕

| 项目 | 口径 | 对公式的影响 |
|---|---|---|
| 计算周期 | 每天 00:00–24:00，同一排班逐日循环 | 日产出 = A 班 + B 班 |
| 班次长度 | 整数小时，各设施 A 班均从 00:00 开始，B 班为互补的 `24−h_A` | 决策变量只有一个整数 `h_A` |
| 在岗与离岗 | 在岗**只消耗**心情，真正离岗后才**回复** | 心情只在「工作段」减少、在「休息段」增加 |
| 满心情 | 100%，内部按 1 计算 | 所有心情量用 [0,1] 表示 |
| 人员约束 | 每人每天仅一段工作，不跨设施重复上岗 | A/B 两组必须互斥且全域唯一 |
| 产出单位 | 基础产速下的**等效生产小时** | 只比较同种产物，不跨产物相加 |
| 设施规模 | 制造舱 ×2、培育舱 ×1、中枢 ×1、会客室 ×1，每设施 3 人 | 人数项 N=3 ⇒ 2.2 |

### 1.2 符号表

| 符号 | 含义 | 单位 |
|---|---|---|
| `N` | 该设施在岗人数 | 人 |
| `b` | 当前配方适用的**生产加成合计**（同配方内加算） | 小数 |
| `r` | 该设施**心情减免合计** | 小数 |
| `u(t)` | 当前中枢**回复加成合计**（中枢失效时为 0） | 小数 |
| `E` | 生产倍率（含人数项） | 倍 |
| `d` | 每人每小时心情消耗 | 1/小时 |
| `v(t)` | 离岗干员每小时心情回复 | 1/小时 |
| `h` | 排定班长（整数小时） | 小时 |
| `H` | 本班**有效生产小时**（不含归零后的等待） | 小时 |
| `C` | 本班心情**实际消耗**（≤1） | [0,1] |
| `R` | 离岗到下次上岗之间**可获得**的回复量 | [0,1] |
| `Δt_k` | 休息段落在第 k 个中枢阶段的时长 | 小时 |
| `Y` | 等效生产小时（产出度量） | 小时 |
| `T` | 满心情连续有效工作的理论时长 | 小时 |
| `q` | 某产物的基础产速 | 单位/小时 |

### 1.3 基础常数〔原文〕

| 常数 | 取值 | 说明 |
|---|---|---|
| 基础心情消耗 | `7.2%`/小时 | 无减免时的消耗速度，即 0.072 |
| 基础心情回复 | `12%`/小时 | 无中枢加成时的回复速度，即 0.12 |
| 人数项系数 | 每人 `+40%` | `1 + 0.40N`；3 人 = 1 + 1.2 = **2.2** |
| 零心情规则 | 归零即停产，等到整点才离岗 | 等待段**不计产出、不回心情**，但**计入班长 h** |
| 中枢归零规则 | 中枢干员归零后可留岗，但其 `u` **失效** | `v(t)` 需按失效时刻分段 |
| 技能升级 | 新档覆盖旧档，不叠加各精英化阶段 | 一次只取一个档位的数值 |
| 心情上限 | 100%，回复到满即止，不储存 | `R` 只需 ≥ `C` |

## 2. 三个核心公式〔原文〕

```text
E    = (1 + 0.40·N) · (1 + b)
d    = 0.072 · (1 − r)
v(t) = 0.12 · (1 + u(t))
```

- **效率 `E`**：人数项与配方加成项**相乘**。3 人满编 2.2；3 个 30% 加成合计 b=0.90，则 `E = 2.2 × 1.90 = 4.18`，即 **418%**。
- **消耗 `d`**：减免从 1 中扣除后再乘基础消耗。`r=0.36` ⇒ `d = 0.072 × 0.64 = 0.04608`，即 **4.608%/小时**。
- **回复 `v`**：中枢加成**只作用于回复**，且随时间可变（中枢归零失效）。

三条公式相互独立：`b` 不影响心情，`r`/`u` 不影响效率。这是全部排班推演的基础。

## 3. 生产段：有效工作小时与产出

### 3.1 有效工作小时

```text
H = min( h , 1/d )
Y = E · H
```

〔推导〕满心情 1 只能支撑 `1/d` 小时（=`T`）。若排定班长 `h > 1/d`，则耗尽后停产，等待片段不计产出，故有效工作小时取两者较小值。

**关键规则**〔原文〕：`13.8889` 小时**不能**四舍五入成 `14` 小时后再按满效率算产出——多出的 `0.1111` 小时是停产等待，产出必须用 `H = 1/d` 计。

### 3.2 日产出与平均效率

```text
Y日      = Y_A + Y_B = E_A·H_A + E_B·H_B
平均效率  = Y日 / 24
```

- 平均效率的分母是**该设施自身占用的小时数（24）**。
- 若要报告「平均每座制造舱的效率」，分母必须是 `2 × 24 = 48`，**不能**把两舱合计产出除以 24 后当成单舱效率。
- 等效小时只能**同种产物**比较；菌类 418% 的组合不能给晶植提供 418%。

### 3.3 换算为实际产量

```text
产量 = q × Y日
```

未给配方基础产速 `q` 时，用等效小时保持可比较性；它表示**连续生产进度**，不等于已完成整批物品数量。

## 4. 心情段：消耗、回复与闭环判定

### 4.1 本班消耗

```text
C = min( 1 , d · h )
```

同设施三人承受同一 `r`，消耗速度相同，按**共同耗尽点**统一计算；`C` 天然上限为 1（心情不会降到负值）。

### 4.2 离岗可回复量与可行性

```text
R = Σ_k  v_k · Δt_k        可行 ⟺ R ≥ C
```

- 休息窗口 = 本班离岗时刻 → 下一次上岗时刻，即 `[h_A, 24]`（A 组）或 `[0, h_A]`（B 组）。
- **归零后的等待时间不能计入 `Δt`**：等待发生在在岗状态，不回心情。
- 只要 `R ≥ C`，每轮都能回到满心情，排班即可逐日重复；`R < C` 则每天净亏心情，方案**不可持续**。

### 4.3 回满需时与余量

```text
t满 = min{ t : Σ_k v_k·Δt_k ≥ C }
余量 = 休息小时 − t满
```

跨中枢阶段时**必须按时间先后累积**，达到缺失量即停止（回满后不再储存）。这与可行性判定不同：判定只看总量够不够，`t_满` 必须按顺序走。

**分段算法**（`v` 随中枢阶段变化时通用）：

```
回满需时(C, 休息窗口):
    t ← 0; need ← C
    for 中枢阶段 k in 覆盖休息窗口的阶段(按时间顺序):
        dt ← overlap(休息窗口, 阶段 k) 的时长
        v_k ← 0.12 × (1 + u_k)          # 中枢失效则 u_k = 0
        if need ≤ v_k × dt: return t + need / v_k
        need ← need − v_k × dt; t ← t + dt
    return ∞                            # 回不满 ⇒ 方案不可持续
```

### 4.4 工作上限与工作休息比

```text
T = 1 / d          工作休息比上限 = v / d
```

〔推导〕工作 `h` 小时需 `dh` 心情，至少休息 `dh / v` 小时。

| 减免档 | `d` (/小时) | `T = 1/d` | `v/d`（中枢 17.76%/h 时） |
|---|---|---|---|
| 无减免 | 7.200% | 13:53:20 | 2.467 : 1 |
| 18% | 5.904% | 16:56:16 | 3.008 : 1 |
| 36% | 4.608% | 21:42:05 | 3.854 : 1 |
| 50% | 3.600% | 27:46:40 | 4.933 : 1 |
| 54% | 3.312% | 30:11:36 | 5.362 : 1 |

注意：`T` 可以大于 24 小时，但**真正的约束是 24 小时轮转下的休息窗口**——`T > 24` 不代表能连上 24 小时。

## 5. 边界规则（决定模型是否自洽）

| 规则 | 内容 | 计算含义 |
|---|---|---|
| 归零停产 | 制造/培育/会客的心情归零即停产，直到排定整点统一离岗 | 产出截断在 `1/d`，但 `h` 仍按整点算，形成停产等待 `h − 1/d` |
| 等待不回复 | 等待段既不计产出也不回心情 | 休息窗口从**离岗整点**起算，不能提前 |
| 中枢失效 | 中枢干员归零后留岗但 `u = 0` | 中枢若排到耗尽点之后，休息干员按失效前后**分段**算 `v` |
| 整点操作 | 换人只在整点发生 | 决策变量离散为 1…23 小时；`T`、`t_满` 只用于校验，不要求玩家按秒操作 |
| 中枢覆盖 | 生产组的休息应尽量落在高 `u` 阶段 | 先定中枢 A/B 时段，再排生产班（§7.2） |

## 6. 技能取值、叠加与练度

| 规则 | 内容 |
|---|---|
| 同配方内加算 | 不同干员的适用数值技能**相加**后进入 `b`（或 `r`）；不存在乘算 |
| 跨配方隔离 | 晶植加成不计入矿物或菌类效率；武器经验加成不计入干员经验 `b` |
| 覆盖不累加 | 同一技能按新档覆盖旧档，不把 α/β/γ 各阶段全部相加 |
| 线索概率不入乘法 | 线索概率技能只决定**线索倾向**，不进入 `E`；会客定量产出只用会客效率与心情减免。〔原文〕 |
| 同类不叠加 | 相同线索倾向遵循原技能「同类不可叠加」说明 |
| 练度取最高要求 | 岗位同时需要「生产」与「减免」技能时，练度取两者中**更高的精英化**（如经验 30% 需精三、减免 18% 需精四 ⇒ 精四） |
| 「仅进驻」 | 当前配方只利用满编人数（`N`），不依赖该角色技能练度；换配方须重新核对门槛 |

## 7. 排班算法

### 7.1 目标函数

```text
max  Σ_f  Y日(f)
s.t. R(f,g) ≥ C(f,g)   对所有设施 f 与班次 g
     人员互斥（每人每天仅一班）
```

〔原文〕不同产物无统一价值权重，因此**按产物分别报告**，不把干员经验、武器经验、晶植、矿物、菌类、线索相加为单一总收益。实际求解时给定优先级（本方案：干员经验 > 武器经验；晶植 > 其他质料）。

### 7.2 两层分解

1. **第一层：分组。** 先定互不重复的 A/B 三人组。分组决定 `b`、`r`，进而决定 `E`、`d`、`T`。
2. **第二层：定班长。** 名单固定后，对每个设施枚举 `h_A = 1…23`（`h_B = 24 − h_A`），取可行且日产出最大的组合。

固定名单下的整小时枚举可以直接求出最高日产出；**跨设施换人**还必须检查「被换出岗位的损失」——同一角色在别处也有技能，并不代表能在同一 24 小时内再排第二班。

### 7.3 伪代码

```
for hA in 1..23:
    hB ← 24 − hA
    for each 设施 f in {制造1, 制造2, 培育, 会客}:
        (b_A, r_A) ← 汇总(f.A 名单, 配方)        # §6
        (b_B, r_B) ← 汇总(f.B 名单, 配方)
        E_A ← (1 + 0.40·N)·(1 + b_A);  d_A ← 0.072·(1 − r_A)
        E_B ← (1 + 0.40·N)·(1 + b_B);  d_B ← 0.072·(1 − r_B)
        H_A ← min(hA, 1/d_A);          H_B ← min(hB, 1/d_B)
        C_A ← min(1, d_A·hA);          C_B ← min(1, d_B·hB)
        if 回满需时(C_A, [hA, 24]) > hB: continue   # A 组休息不够
        if 回满需时(C_B, [0, hA])  > hA: continue   # B 组休息不够
        Y ← E_A·H_A + E_B·H_B
        记录(hA, Y)
取可行方案中 Y 最大者
```

### 7.4 判定流程清单（换人/换配方后的检查顺序）〔原文〕

1. 更新对应技能数值与**最高练度**；
2. 重算 `E`、`d`、`T`；
3. 重算各整数班长的 `H` 与日产出；
4. 检查两组 `R ≥ C`（含跨中枢阶段分段）；
5. 检查人员唯一性（不重复上岗）；
6. 检查中枢覆盖是否仍成立（生产组休息是否仍在高 `u` 阶段）。

### 8.4 完整算例：培育晶植〔原文 + 复算〕

```
b_A = 30% + 30% + 30% = 90%      r_A = 18%
E_A = 2.2 × (1 + 0.90) = 4.18    d_A = 0.072 × (1 − 0.18) = 0.05904
H_A = min(17, 1/0.05904) = min(17, 16.937669) = 16.937669
Y_A = 4.18 × 16.937669 = 70.79946
B 组：b_B = 0 → E_B = 2.2；r_B = 18% → d_B = 0.05904
       H_B = min(7, 16.937669) = 7 → Y_B = 2.2 × 7 = 15.40
Y_日 = 70.79946 + 15.40 = 86.19946      平均效率 = 86.19946 / 24 = 359.16%
```

### 8.5 敏感性：诀的加成 20% → 30%〔复算 = 原文〕

| 指标 | 20% | 30% |
|---|---|---|
| A 组晶植加成 `b_A` | 80% | 90% |
| A 组 `E_A` | 396% | 418% |
| A 组 `Y_A` | 67.07317 | 70.79946 |
| 晶植 `Y_日` | 82.47317 | 86.19946 |
| 全天平均效率 | 343.64% | 359.16% |

增量 `+3.72629` 等效小时（`+4.52%`）。**只影响 `E`，不改变 `d`、耗尽点、回满时间与 17/7 的班长选择**——因为该修正不触及心情维度。

## 9. 组合效率与配方切换

### 9.1 培育舱各作物组合（满技能且在岗心情有效时）

| 三人组合 | 晶植 | 矿物 | 菌类 |
|---|---|---|---|
| 汤汤 别礼 诀 | 418% | 286% | 220% |
| 伊冯 提弗洛斯 弭弗 | 220% | 286% | 418% |
| 诀 提弗洛斯 汤汤 | 352% | 352% | 286% |
| 伊冯 别礼 弭弗 | 286% | 220% | 352% |

计算逻辑：`E = 2.2 × (1 + 该质料加成合计)`，同一行内三种质料各自独立汇总。例如「伊冯 提弗洛斯 弭弗」的晶植无任何加成（`b = 0`），故 `2.2 × 1.0 = 2.20`；其菌类为伊冯 30% + 弭弗 30% = 60%，故 `2.2 × 1.6 = 3.52`；其矿物只有提弗洛斯 30%，故 `2.2 × 1.3 = 2.86`。前两行是当前 A/B 组，后两行是另一套互斥组合，不能同时使用。**更换作物优先级必须重新选择主力与班长。**

### 9.2 配方切换的连锁影响

`b` 变 ⇒ `E` 变（产出变）；若同时换了带减免的干员，`r` 也变 ⇒ `d`、`T`、`C`、`R` 全变。因此「切换配方」不是只换乘数，而是要**重跑 §7.4 全流程**。

## 10. 模型边界（这些不做，别误用）

| 未建模项 | 说明 |
|---|---|
| 配方基础产速 `q` | 结果以等效小时给出，不换算成具体物品数 |
| 整批完成与库存上限 | 只算连续生产进度，不承诺整批产出 |
| 多产物统一价值权重 | 无权重，故分别报告，不相加 |
| 线索概率的定量收益 | 概率技能不计入 `E`，只作倾向说明 |
| 心情激励点数（好友助力） | 未进入本模型 |
| 全局最优性 | 结论以「当前目标 + 当前人员」为条件，非所有目标下的最优证明 |

## 11. 一页速查

```
E  = (1+0.40N)(1+b)          # 秒算：3 人满编 2.2，再乘 (1+加成合计)
d  = 0.072(1−r)              # 秒算：7.2% 乘 (1−减免合计)
v  = 0.12(1+u)               # 秒算：12% 乘 (1+中枢加成合计)
H  = min(h, 1/d)             # 超过 1/d 的部分是停产等待，不计产出
Y  = E·H                     # 等效小时；日产出 = Y_A + Y_B
C  = min(1, d·h)             # 本班消耗
R  = Σ v_k Δt_k              # 分段累加；R ≥ C 才可逐日循环
Y日/24 = 全天平均效率         # 双舱平均请用 /48
```
