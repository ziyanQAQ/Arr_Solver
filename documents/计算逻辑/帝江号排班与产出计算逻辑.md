# 帝江号排班与产出计算逻辑

> 本文是**求解器规格**：给定干员池与配方，算出一套产量最高且稳定的布局（每个设施几点换班、两班各是谁）。
> 常数取自客户端 `TableCfg\SpaceshipConst.json` 与 `LuaScripts\Common\Utils\SpaceshipUtils.lua`。
> 单舱细则见 `帝江号制造舱产出计算逻辑.md`、`帝江号培养舱产出计算逻辑.md`、`帝江号会客室信用计算逻辑.md`。

## 0. 术语

| 术语 | 定义 |
|---|---|
| **布局** | 一套完整方案 = 中枢配置 + 四个设施各自的配置 |
| **时间轴** | 中枢的换班时刻与两班名单，它决定全船每个时段的回复加成 `u(t)`。**全船只有一条时间轴** |
| **中枢配置** | `(中枢班长, 中枢 A 组, 中枢 B 组)`，即一条时间轴的完整描述 |
| **交换时刻 / 班长** | 该设施 A 班的下班时刻，也是 A 班的小时数（整数 1..23）。B 班 = `24 − 班长` |
| **班次** | 一个设施的一次值班：A 班 `00:00–班长`，或 B 班 `班长–24:00` |
| **候选** | 某设施的一种可能配置：`(模式, 班长, A 组, B 组)` |
| **分支** | 搜索过程中已确定下来的那部分布局 |

## 1. 口径

| 项 | 口径 |
|---|---|
| 计算周期 | 每天 00:00–24:00，同一布局**逐日循环**，周期必须闭合 |
| 换班 | **定点自动、只能设在整点**，不考虑手动换班 |
| 班次模式 | 每个设施可独立选**两班**（A/B 自动轮换）或**单班**（只有一组人） |
| 两班的人数约束 | **每班至少 1 人**；任一班为空 ⇒ 该班 0 人在岗 ⇒ 停产，且自动轮换被强制关闭 |
| 人员约束 | 每人每天仅一段工作，不跨设施重复上岗 |
| 设施等级 | 本文按满级算：中枢 Lv5、制造舱 ×2 / 培养舱 / 会客室均 Lv3（各 3 工位）。代码实现需支持逐账号的等级与技能档位差异 |
| 人数项 | 每名**实际在岗**者 **+40 进度/秒**（= +40%）；**总控中枢没有人数项** |
| 白板干员 | 在制造/培养/会客仍有 `+40%`；**在中枢贡献为 0**（中枢只认恢复技能） |
| 红脸 | 心情归零 → 立即停产、离岗、进驻技能全部失效、**视为不在设施内**（人数项按剩余在岗人数扣减）；回满 100% 自动返岗 |
| 产出单位 | **等效小时** = `速率/100 × 时长`，只比较同种产物 |

## 2. 常数与速率

### 2.1 常数

| 常数 | 值 | 含义 |
|---|---|---|
| `basePhysicalStrengthCostRate` | 12 / 分钟 | ⇒ 心情消耗基数 **7.2%/h** |
| `basePhysicalStrengthRecoveryRate` | 20 / 分钟 | ⇒ 心情回复基数 **12%/h** |
| `maxPhysicalStrength` | 10000 | 满心情（= 1） |
| `default*ProduceRate` | **100 进度/秒** | 100% 速率 |
| `base*ProduceRate` | **40 进度/秒/人** | 人数项 |
| `clueCollectPointMaxValue` | 8,800,000 | 会客室一张线索的进度 |

### 2.2 统一速率式

```text
速率 = (100 + 40 × 在岗人数) × (1 + Σ技能加成)      [进度/秒]
倍率 = 速率 / 100
```

| 在岗人数 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 速率 | 100 | 140 | 180 | 220 |
| 倍率 | 1.00 | 1.40 | 1.80 | **2.20** |

### 2.3 四设施的属性差异

| 设施 | 速率属性 | 基础 | 每人在岗 | 技能 | 隔离方式 |
|---|---|---|---|---|---|
| 制造舱 | 干员培养素材效能 / 武器培养素材效能 | 100 | +40 | `effectType=7` | 按 `expType` 分开 |
| 培养舱 | 菌类 / 晶植 / 矿物培养效能 | 100 | +40 | `effectType=3` | 按 `materialType` 分开 |
| 会客室 | 干员线索收集效能 | 100 | +40 | `effectType=4` | 线索概率不进速率 |
| 总控中枢 | 全员心情恢复/小时 | 20/分钟 | **无** | `effectType=0`（8/12/16%） | 只影响 `v` |

> 一个设施有多条速率属性时，**配方决定吃哪一条**：同一间制造舱产干员经验与产武器经验的速度可以完全不同。

### 2.4 单件 / 单张耗时（100% 速率）

| 产物 | 进度上限 | 100% 耗时 |
|---|---|---|
| 培养舱 金色 R5 质料 | 45,000,000 | **125 h** |
| 制造舱 高级认知载体 | 8,800,000 | **24.4444 h** |
| 制造舱 武器检查套组 | 3,520,000 | **9.7778 h** |
| 会客室 一张线索 | 8,800,000 | **24.4444 h** |

```text
单件耗时 = 进度上限 / (100 × 3600 × 倍率)   小时
```

## 3. 生产段

```text
H = min(h, 1/d)
Y = E · H
Y日 = E_A·H_A + E_B·H_B        # 两班模式
```

- `h > 1/d` 的部分是**停产等待**：不计产出、不回心情，但仍占班长与工位。
- **班内红脸允许**：不构成约束，只让 `H` 截断在 `1/d`、`C` 顶到 100%。
- `13.8889` 不能四舍五入成 `14` 再按满效率算——多出的部分是停产，不是生产。

## 4. 心情模型

### 4.1 单人轨迹

```text
在岗：每小时 −d，d = 0.072 × (1 − r)
离岗：每小时 +v，v = 0.12 × (1 + u(t))
满值：1（10000 点），回满即止，不储存
```

### 4.2 红脸

| 后果 | 内容 |
|---|---|
| 生产 | 立即停产（不等整点） |
| 技能 | 进驻技能全部失效（含中枢的 `u`） |
| 人数项 | 视为不在设施内 ⇒ 按剩余在岗人数扣减 |
| 去向 | 回满 100% 才自动返岗 |

> 人数项扣减**不改变任何产出数字**：同舱减免 `r` 是舱级单值 ⇒ 同组人同时红脸 ⇒ 整舱停产 ⇒ `H` 已经截断，之后乘任何时长都是 0。

### 4.3 中枢的 `u(t)`：两段强度为什么不同

`u` 只在中枢干员在岗且未红脸时生效：

```text
u(t) = Σ（当前时段在岗的中枢干员的恢复技能）
中枢按自己的交换时刻分段：[0, h_中枢) 用 A 组，[h_中枢, 24] 用 B 组
```

**关键事实：两组不可能都满编 48%。** 恢复技能只有两档：

| 档位 | 人数 | 干员 |
|---|---|---|
| 16% | **5 人** | 黎风、梨诺、大潘、萤石、昼雪 |
| 12% | 5 人 | 佩丽卡、艾维文娜、卡契尔、埃特拉、阿列什 |

两班各 3 工位 = 6 人次，而 16% 档只有 5 人 ⇒ 最多一组 48%，另一组最高 44%（16+16+12）。

**哪一组必须强？** A 班的休息窗 `[班长, 24]` 落在**中枢 B 段**，而 A 班是最长的班、`C` 最大。所以：

- **中枢 B 组必须 ≥ 45.9%**（撑住制造1 的 19 h）；
- **中枢 A 组没有下限**：它只服务 B 班，B 班的 `C` 最大 72%，即使 `u = 0`（`v = 12%`），14 h 也能回 168%。

因此中枢的最低配置是：**B 组 3 名 16%（48%），A 组 ≥1 人（白板也可以，或别处用不上的 12% 档）**。

| 本方案取值 | 名单 | `u` | `v` |
|---|---|---|---|
| 中枢 A 段（0–17） | 艾维文娜（12%，别处无用途） | 12% | **13.44%** |
| 中枢 B 段（17–24） | 黎风 + 梨诺 + 大潘（各 16%） | 48% | **17.76%** |

> 中枢没有心情减免技能 ⇒ `d = 7.2%/h` 恒定 ⇒ **连续在岗上限 `1/0.072 = 13.889 h`**，超出则该段 `u = 0`；红脸后要 `1/0.12 = 8.333 h` 回满。

### 4.4 稳定性判据

**两班**：每个班次都要能回满

```text
R = Σ_k v_k · Δt_k        C = min(1, d·h)
稳定 ⟺ R ≥ C
```

**单班**：没有 B 组接班，靠“红脸后回满”循环

```text
周期 = 1/d + t满
```

**不稳定方案怎么算**（决定“能不能用”的核心）

若 `R < C`，方案不会第一天就崩，而是**逐日衰减**：每天只回得起 `R`，第二天开工时就只有 `R` 的心情，当天最多只能干 `R/d` 小时。

```text
稳定的日产出   = 速率 × min(班长, 1/d)      # R ≥ C，可逐日重复
不稳定的长期值 = 速率 × R / d                # 稳态下每天只能干 R/d 小时
判定：两者取高
```

| 情况 | 取哪个 |
|---|---|
| 不稳定的长期值 < 降级后的稳定值 | **降级** |
| 不稳定的长期值 > 降级后的稳定值 | **不降级**，接受衰减 |

> 例：会客室不降级时第一天 9 张、稳态只有 6 张；降级后稳定 8 张 ⇒ 选降级（8 > 6）。若降级后只有 5 张 ⇒ 不降级（6 > 5）。
> **降不降级只由效率决定，不由优先级决定**——会客室自己也可以被降级。

### 4.5 回满需时

```text
t满 = min{ t : Σ_k v_k·Δt_k ≥ C }
余量 = 休息小时 − t满
```

按时间先后累积，达到缺失量即停（回满不储存）：

```
回满需时(C, 窗口, u(t)):
    t ← 0; need ← C
    for 中枢阶段 k in 覆盖窗口的阶段(按时间顺序):
        dt ← overlap(窗口, k);  v_k ← 0.12 × (1 + u_k)     # 红脸段 u_k = 0
        if need ≤ v_k × dt: return t + need / v_k
        need ← need − v_k × dt;  t ← t + dt
    return ∞                          # 回不满
```

## 5. 班次模式

### 5.1 两班

```text
h_B = 24 − h_A            # h_A 取整数 1..23
Y日 = E_A·H_A + E_B·H_B
约束：两班各 ≥1 人；两组人员互斥；各自满足稳定性判据
```

### 5.2 单班

```text
周期 = 1/d + t满
Y日  = E · (1/d) · 24 / 周期
在岗占比 = (1/d) / 周期
```

周期通常不是 24 的整数倍 ⇒ 单班产出是**归一到 24 h 的长期平均**，不保证每天相同。

### 5.3 两班 vs 单班（制造1，A 组 `b=90% / r=36%`，`E=4.18`）

| 模式 | 计算 | 日产出 |
|---|---|---|
| 两班（19/5，B 组 `b=60%`） | `4.18×19 + 3.52×5` | **97.02** |
| 两班（19/5，B 组只有白板 `b=0`） | `4.18×19 + 2.2×5` | **90.42** |
| 单班（中枢在岗 48%） | `T=21.70`，回满 5.63，周期 27.33，占比 79.4% | **79.65** |

能开两班就开两班；人不够或第二组只能放白板时才转单班。

## 6. 求解

### 6.1 目标：字典序

```text
max 会客室 ≻ 制造舱（干员经验）≻ 制造舱（武器经验）≻ 培养舱
```

中枢没有产出，它只决定“可行域”，不参与比较。前一级吃满才轮到下一级。

### 6.2 变量与层级

| 层级 | 变量 | 说明 |
|---|---|---|
| **全船唯一** | 中枢配置 `(h_中枢, A 组, B 组)` | 它定义时间轴与 `u(t)`，四个设施共用同一条 |
| 每设施独立 | 模式（两班/单班）、`h_f`、A 组、B 组 | 互不影响，只受“人员唯一”约束 |

> **时间轴只有一条。** 设施的 `h_f` 各自独立，但它们看到的 `u(t)` 必须来自同一个中枢配置——不能出现“会客室按 20:00 算、制造舱按 14:00 算、中枢各配各的”。

### 6.3 约束

1. 每人每天仅一段工作（跨设施唯一）。
2. 两班模式下每班 ≥ 1 人。
3. 每个班次满足 §4.4 的稳定性判据（用同一条 `u(t)` 分段计算）。
4. 中枢白板贡献为 0；其他设施白板贡献 `+40%`。

### 6.4 算法：字典序分支定界

**外层枚举时间轴，内层排人**。这样中枢配置只落地一次，不会出现“每个设施各用一套时间轴”的错误。

```text
# ① 外层：枚举中枢配置（= 枚举时间轴）
for 中枢配置 C0 in 全部(中枢 h ∈ 1..23, A组, B组):
    按 §6.6 粗筛：u 超出需求、或红脸空窗不安全 的配置直接跳过

    S ← { C0 }                              # 分支集合，每条分支都带同一个 C0

    # ② 内层：按优先级把设施挂到这条时间轴上
    for 设施 f in (会客室, 制造1, 制造2, 培养舱):
        for s in S:
            V(s) ← max{ 产出(f, 候选) : 候选 ∈ f 的全部(模式, 班长, A组, B组)，
                        满足 每人唯一 / 每班≥1人 / 用 C0 判 §4.4 }
        L ← max over s of V(s)              # 本级最优值
        S ← { s ∪ 该候选 : V(s) == L }       # 只留达到本级最优的分支
        若 S 为空 → 按 §6.7 降级 f 后重跑本级；仍为空则记缺口并跳过

    # ③ 这条时间轴下的四级最优得分已确定
    记下 (C0, S)

# ④ 在所有中枢配置里取字典序得分最高的一组，作为最终布局
按 §6.8 同分裁决从该组的 S 中取一个输出
```

| 步骤 | 作用 |
|---|---|
| ① 外层循环 | 这就是「先试中枢几点换班」：23 种换班时刻 × 中枢两组名单，全部试过 |
| ② 内层循环 | 在这条时间轴上按优先级排设施；每个设施自己枚举 1..23 的班长 |
| §4.4 判据 | 任何设施不满足就淘汰**这条分支**（这个设施的排法在此时轴上不成立） |
| ③ 记录 | 四个设施都排完，得到 `(会客, 制造干员, 制造武器, 培养)` 四个数 |
| ④ 比较 | 字典序比较四元组，取最高的那条时间轴及其布局 |

**为什么外层必须是中枢**

- 中枢是**唯一同时影响所有设施**的量（`u` 一掉，所有 A 班一起掉）；
- 中枢只有 23 种换班时刻，是最小的枚举维度；
- 不先固定它，就无法评估任何车间（评估车间要先知道回血速度，而回血速度来自中枢）。

**剪枝规则**

| 剪枝 | 做法 |
|---|---|
| 产出剪枝 | 本设施产出 < 本级最优 `L` 的分支直接丢弃 |
| 人员集合去重 | 产出相同且**占用人员完全相同**的候选只留一个 |
| 中枢配置粗筛 | 中枢无产出，`u` 超过需求的部分无收益 ⇒ 只留“刚好能让所有已分配设施回满”的配置 |
| 中枢按需升级 | 中枢先给最小值，只有当前设施提高 `u` 需求时才升档，且只升到刚够 |

> 产出相同但**占用人员不同**的候选必须全部保留，否则会漏掉后续最优。

### 6.5 候选的枚举与判定顺序

对某个设施，候选按下列顺序生成与筛选，**任何一步不过就丢弃该候选**：

```text
1. 选模式：先试「两班」，再试「单班」
2. 两班：班长 h = 1..23；单班：无班长
3. 选 A 组的干员组合（从剩余池里选）
4. 选 B 组的干员组合（两班时；从 A 组之外选）
5. 判「每班 ≥1 人」
6. 判「每人唯一」（与已锁定设施不冲突）
7. 判 §4.4 稳定性（用当前时间轴的 u(t) 分段）
8. 全部通过 → 计算该候选的日产出，进入竞争
```

> 步骤 7 不通过时**不要立刻丢掉**：按 §4.4 算一下“不稳定长期值”，它可能仍高于降级后的稳定值。

### 6.6 中枢的最低限制

```text
中枢最低限制 = 满足「所有已分配设施的每个班次都稳定」的中枢配置中，
               按 ① 人数最少 ② 机会成本最低 依次取最小的那个
```

- **①人数最少**：能用 1 人满足就不上 2 人。
- **②机会成本最低**：优先用「另一槽在别处无效率价值」的人。
  - 零成本：黎风（会客概率）、梨诺（会客心情，B 班用不上）、艾维文娜（会客概率）、阿列什（会客概率）
  - 高成本：大潘（培养菌 20%）、萤石（培养矿 20%）、昼雪（制造心情 14%）、佩丽卡（制造武器 30%）、埃特拉（会客 30%）

**中枢各段的需求下限**

| 中枢段 | 服务的对象 | 需求 |
|---|---|---|
| B 组 `[h_中枢, 24]` | 所有 A 班的休息窗 | **必须 ≥ 45.9%**，即三人全 16% |
| A 组 `[0, h_中枢)` | 所有 B 班的休息窗 | 只需 ≥1 人；`u = 0` 也够（B 班 `C` ≤ 72%，14 h 回 168%） |

中枢的 `u` 是全船唯一同时影响所有设施的量：

| 中枢某段在岗 | `u` | `v` | 5 h 休息窗能回 | 制造1A 需要 |
|---|---|---|---|---|
| 三人 16×3 | 48% | 17.76% | 88.80% | 87.55% ✔ 余量 4 分 13 秒 |
| 两人 16+16 | 32% | 15.84% | 79.20% | ✘ |
| 一人 16 | 16% | 13.92% | 69.60% | ✘ |
| 无人 / 白板 | 0 | 12.00% | 60.00% | ✘ |

**补人来源顺序**：① 剩余池 → ② 降级最后分配的设施 → ③ 记缺口。

**中枢红脸空窗判据**（整点换班带来的必然问题）

中枢连续在岗上限 `13.889 h`，而换班只能整点 ⇒ 某一段只能取 13 h、14 h 或更长：

| 中枢段班长 | 情况 |
|---|---|
| ≤ 13 h | 全程有 `u` |
| 14 h | 末 7 分钟 `u = 0`，是否可接受看判据 |
| ≥ 15 h | 空窗 ≥ 1.111 h，几乎必然影响别人 |

```text
判据：所有被该段服务的班次，t满 ≤ 13.889 h
      （中枢红脸之前，需要回血的人都已经回满了）
```

- 满足 ⇒ 可排 14 h 或更长；
- 不满足 ⇒ 该段必须缩短，或调整对应设施的班长。

### 6.7 降级动作集

某设施凑不出稳定形态时，四种动作各算一遍，取日产出最高者：

| 动作 | 效果 | 代价 |
|---|---|---|
| 缩短班长 `h_f` | 休息窗变长 ⇒ `R` 变大 | 直接损失 `H` |
| 减少人数 | 人数项与技能一起掉 | 约 −31%（3→2 人） |
| 降低档位（30%→20%） | `b` 下降 | 约 −5%~−10% |
| 转单班 | 周期变长，但省下一整组人 | 约 −12%，释放 3 个人次 |

牺牲顺序按 §6.1 倒序：培养舱 → 制造2 → 制造1 → 会客室。但**任何设施都可以用这四种动作，包括会客室自己**——它没有更低优先级可让时只能自救。

### 6.8 同分裁决

1. 对中枢要求更低的；
2. 占用干员更少的；
3. `h_f` 更大的；
4. charId 稳定序。

### 6.9 输出内容

| 项 | 内容 |
|---|---|
| 布局 | 中枢：换班时刻 + 两组名单；四设施：模式、换班时刻、两组名单 |
| 产出 | 每设施日产出（等效小时）、折算件数 / 张数 / 经验；培养舱给单槽与整舱 |
| 心情 | 每班次的 `C`、`R`、`t满`、余量；中枢每段的红脸时刻与空窗是否安全 |
| 稳定性 | 每班次是否稳定；只能取不稳定形态的设施标注长期衰减值 |
| **练度建议** | 只针对**已有干员**：每个干员的每个技能「升一档」能带来多少全船增量，按增量排序。不输出获取新干员的建议 |
| 缺口 | 降级后仍不可行的设施差在哪（差几名干员 / 差哪个档位 / 班长最多几小时） |

> 练度建议需额外输入每个技能的**当前档位**（α/β/γ）；本文主算按最高档。

### 6.10 一次完整走查

以本仓库的示例布局为例，走一遍外层的一次迭代：

```text
中枢配置 C0 = (h=17, A组=艾维文娜12%, B组=黎风+梨诺+大潘 各16%)
   ↓ u(t)：[0,17) → 12%（v=13.44%）；[17,24] → 48%（v=17.76%）

② 会客室：枚举后取 20/4
     A 组 洛茜+艾尔黛拉+祀（90% 收集、54% 减免）→ E=4.18、d=3.312%
     B 组 埃特拉(30%)+秋栗(18%)+占位 → E=2.86、d=5.904%
     A 班休息 [20,24] ⊂ 中枢 B 段 → R = 4×17.76% = 71.04% ≥ C=66.24% ✔
     产出 = 83.60 + 11.44 = 95.04 → 锁定

③ 制造1（干员经验）：取 19/5
     A 组 莱万汀+庄方宜+余烬（90%、36%）→ E=4.18、d=4.608%
     B 组 卡缪+噗切娜+占位（60%、0%）→ E=3.52、d=7.2%
     A 班休息 [19,24] → R = 5×17.76% = 88.80% ≥ C=87.552% ✔ 余量 4 分 13 秒
     产出 = 79.42 + 17.60 = 97.02 → 锁定

④ 制造2（武器经验）：取 19/5
     A 组 佩丽卡+洁尔佩塔+骏卫（90%、36%）；B 组 陈千语+弧光+安塔尔（60%、0%）
     产出 = 97.02 → 锁定

⑤ 培养舱（晶植）：取 17/7
     A 组 别礼+汤汤+诀（90%、18%）→ E=4.18、d=5.904%
     A 班休息 [17,24] → R = 7×17.76% = 124.32% ≥ C=100% ✔
     产出 = 70.79946 + 15.40 = 86.19946 → 锁定

⑥ 记录得分 (95.04, 97.02, 97.02, 86.19946)
   ↓ 换下一个中枢配置，重复 ②–⑥
⑦ 全部中枢配置比完，取字典序最高的一组输出
```

> 注意 ⑤：培养舱的 `h=17` 正好等于中枢的换班时刻。中枢 B 段从 17:00 开始，培养舱 A 班的休息窗 `[17,24]` 整段落在里面——这就是"中枢换班时刻取各设施最早下班时刻"的直接结果。

## 7. 技能取值

| 规则 | 内容 |
|---|---|
| 同配方内加算 | 不同干员的适用数值技能相加后进入 `b`（或 `r`） |
| 跨配方隔离 | 晶植不计入矿物/菌类；武器经验不计入干员经验 |
| 覆盖不累加 | 同一技能按新档覆盖旧档 |
| 线索概率不进速率 | 只决定线索倾向 |
| 练度取最高要求 | 同岗需要多种技能时取更高的精英化 |
| 「仅进驻」 | 只用人数项的岗位不依赖该角色练度 |

## 9. 一页速查

```text
速率 = (100 + 40×在岗人数) × (1 + Σ技能加成)     # 进度/秒；中枢无人数项
倍率 = 速率 / 100
d    = 0.072(1 − r)                # 中枢恒 7.2%（无减免技能）
v    = 0.12(1 + u)                 # 按中枢分段；红脸段 u = 0，退回 12%
H    = min(h, 1/d)                 # 超出部分是停产等待；红脸允许
Y    = E·H
Y日  = E_A·H_A + E_B·H_B           # 两班
周期 = 1/d + t满；Y日 = E·(1/d)·24/周期   # 单班
R    = Σ v_k·Δt_k
稳定：R ≥ C，日产出 = E·min(h, 1/d)
不稳定：长期只能到 E·R/d            # 与降级后的稳定值比，取高者
中枢 B 组必须 ≥45.9%（三人全 16%）；A 组 ≥1 人即可（B 班 C 小）
中枢某段 > 13.889 h 会出现 u=0 空窗，判据：被服务的班次 t满 ≤ 13.889 h
时间轴只有一条：中枢配置在外层枚举，设施的 h 在内层各自枚举
单件耗时 = 进度上限 / (360000 × 倍率)   # 培养 125h、认知载体 24.4444h、线索 24.4444h
```
