# 帝江号排班与产出计算逻辑

> 本文是**求解器规格**：给定干员池与配方，算出一套产量最高且稳定的布局（每个设施几点换班、两班各是谁）。
> 常数取自客户端 `TableCfg\SpaceshipConst.json` 与 `LuaScripts\Common\Utils\SpaceshipUtils.lua`（这两个路径属于游戏客户端，不在本工作区内；本工作区的数据副本见 `data\ship-data.json`，本文用到的常数汇总在 §2.1）。
> 单舱细则见 `帝江号制造舱产出计算逻辑.md`、`帝江号培养舱产出计算逻辑.md`、`帝江号会客室信用计算逻辑.md`。

## 0. 符号

域术语（布局、时间轴、中枢配置、班长、班次、候选、分支、稳定班、收敛、衰减班、补位变体、限界函数…）统一在根目录 `GLOSSARY.md` 定义，本文不再重复。

| 符号 | 含义 |
|---|---|
| `u` / `v` | 中枢某段的回复加成 / 由它得到的回复速度 `v = 0.12(1+u)` |
| `b` / `r` | 在岗者的加成之和 / 减免之和 |
| `E` | 倍率，`E = (1 + 0.40·在岗人数)(1 + b)`；**日产出、长期值一律乘 `E`，不乘速率** |
| `d` | 心情消耗速度，`d = 0.072(1 − r)` |
| `C` / `R` | 本班消耗 `min(1, d·h)` / 休息窗内可回复量 |
| `t满` | 从休息窗起点回满 `C` 所需的实际小时数（§4.5） |
| `v̄` / `W*` | 休息窗内加权平均回复速度 / 衰减班的长期平均日工作时长（§4.4） |
| `h` | 该设施 A 班的下班时刻（= A 班小时数，整数 1..23）；B 班 = `24 − h` |
| `a` | 每天可用的助力点数，`a ∈ {0,1,2}`，默认 0（§4.6、§6.3 第 5 条） |

**总纲（优先级最高，后面各节都受它约束）**

```text
目标 = 效率（等效小时/日）最大化；心情模型只决定"这个方案能产出多少"，不是准入条件。
"稳定"分两层，不要混用（§4.4）：
  · 狭义稳定（每班 R ≥ C、天天回满）**不是**准入门槛，它只是一种取值方式；
  · 广义长期稳定（长周期收敛到有界稳态、长期均值不漂移）**是**准入门槛。
判录取用长期均值（广义稳定），判取值方式才用 R ≥ C（狭义稳定）。
```

## 1. 口径

| 项 | 口径 |
|---|---|
| 计算周期（生产） | 每天 **00:00–24:00**，同一布局**逐日循环**。两班模式必须闭合；单班模式只要求长期平均，允许相位漂移（§5.2） |
| 计算周期（助力） | **04:00–次日 04:00**，只用于中枢助力的点数刷新与作废（§6.3 第 5 条）。**两套时间基准并存，互不换算** |
| 换班 | **定点自动、只能设在整点**，不考虑手动换班。助力是手动操作，不受整点限制 |
| 班次模式 | 每个设施可独立选**两班**（A/B 自动轮换）或**单班**（只有一组人） |
| 两班的人数约束 | **每班至少 1 人**；任一班为空 ⇒ 该班 0 人在岗 ⇒ 停产，该设施只能按单班模式计 |
| 人员约束 | 每人每天仅一段工作，不跨设施重复上岗 |
| 设施工位 | 中枢 **3**、制造舱 3、培养舱 3、会客室 3。白板也占工位 |
| 设施等级 | 本文按满级算：中枢 Lv5、制造舱 ×2 / 培养舱 / 会客室均 Lv3。代码实现需支持逐账号的等级与技能档位差异 |
| 技能档位 | **每个技能取该干员的最高档：有 γ 用 γ，没有 γ 取 β**。注意有一批技能是 **β 封顶**（如狼卫·狼群的技巧 20%、赛希·标准化编译 20%、阿列什·悠闲垂钓 12%），它们升不到 30% / 16% |
| 人数项 | 每名**实际在岗**者 **+40 进度/秒**（= +40%）；**总控中枢没有人数项** |
| 白板干员 | 在制造/培养/会客仍有 `+40%`；**在中枢贡献为 0**（中枢只认恢复技能） |
| 红脸 | 心情归零 → 立即停产、离岗、进驻技能全部失效、**视为不在设施内**（人数项按剩余在岗人数扣减）；回满 100% 自动返岗 |
| 产出单位 | **等效小时** = `速率/100 × 时长`，只比较同种产物 |

### 2.2 统一速率式

```text
速率 = (100 + 40 × 在岗人数) × (1 + Σ技能加成)      [进度/秒]
倍率 = 速率 / 100
```

| 在岗人数 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 速率 | 100 | 140 | 180 | 220 |
| 倍率 | 1.00 | 1.40 | 1.80 | **2.20** |

### 2.3 四设施的属性差异

| 设施 | 速率属性 | 基础 | 每人在岗 | 技能 | 隔离方式 |
|---|---|---|---|---|---|
| 制造舱 | 干员培养素材效能 / 武器培养素材效能 | 100 | +40 | `effectType=7` | 按 `expType` 分开 |
| 培养舱 | 菌类 / 晶植 / 矿物培养效能 | 100 | +40 | `effectType=3` | 按 `materialType` 分开 |
| 会客室 | 干员线索收集效能 | 100 | +40 | `effectType=4` | 线索概率不进速率 |
| 总控中枢 | 全员心情恢复/小时 | 20/分钟 | **无** | `effectType=0` | 只影响 `v` |

> 中枢恢复技能的档位是 **α 8% / β 12% / γ 16%** 三档。按本文「一律取最高档」，可用的只有 **16%（γ，5 人）** 与 **12%（β 封顶，5 人）** 两档，8% 那个 α 档永远不会出现在候选里。

> 一个设施有多条速率属性时，**配方决定吃哪一条**：同一间制造舱产干员经验与产武器经验的速度可以完全不同。

## 3. 生产段

```text
H = min(h, 起点心情 / d)        # 起点心情见 §4.2；满心情时退化为 min(h, 1/d)
Y = E · H
Y日 = E_A·H_A + E_B·H_B        # 两班模式
```

- **只有“起点满心情”时 `H = min(h, 1/d)` 才成立。** 多日衰减导致起点心情低于 100% 时，`H` 由当天实际心情决定，长期日产出改用 §4.4 的 `W*` 口径——这两件事别混用。
- **红脸 = 心情归零即离岗**（§4.2），从离岗那一刻起按 `v` 恢复。**不存在“留在岗位上干等、不回心情”的时段**；`h > 1/d` 只是让有效时长截断在 `1/d`，多出来的时间人是离岗休息的。
- **班内红脸允许**：不构成约束，只让 `H` 截断在 `1/d`、`C` 顶到 100%。
- `13.8889` 不能四舍五入成 `14` 再按满效率算——多出的部分是红脸离岗，不是生产。

## 4. 心情模型

### 4.1 单人轨迹

```text
在岗：每小时 −d，d = 0.072 × (1 − r)
离岗：每小时 +v，v = 0.12 × (1 + u(t))
满值：1（10000 点），回满即止，不储存
```

### 4.2 红脸

| 后果 | 内容 |
|---|---|
| 生产 | 立即停产（不等整点） |
| 技能 | 进驻技能全部失效（含中枢的 `u`） |
| 人数项 | 视为不在设施内 ⇒ 按剩余在岗人数扣减 |
| 去向 | 回满 100% 才自动返岗 |

> **合并口径下**人数项扣减不改变任何产出数字：同舱减免 `r` 是舱级单值 ⇒ 同组人同时红脸 ⇒ 整舱停产 ⇒ `H` 已经截断，之后乘任何时长都是 0。
> 前提是“无人被单独补过心情”；一旦用助力打破了它（§4.6），同组人会先后红脸，倍率必须按**实际在岗人数**逐段重算（3 人 4.18 / 2 人 2.88 / 1 人 1.82），此时人数项扣减**会**改变产出。

### 4.3 中枢的 `u(t)`：两段强度为什么不同

`u` 只在中枢干员在岗且未红脸时生效：

```text
u(t) = Σ（当前时段在岗的中枢干员的恢复技能）
中枢按自己的交换时刻分段：[0, h_中枢) 用 A 组，[h_中枢, 24] 用 B 组
```

**关键事实：两组不可能都满编 48%。** 恢复技能只有两档：

| 档位 | 人数 | 干员 |
|---|---|---|
| 16% | **5 人** | 黎风、梨诺、大潘、萤石、昼雪 |
| 12% | 5 人 | 佩丽卡、艾维文娜、卡契尔、埃特拉、阿列什 |

两班各 3 工位 = 6 人次，而 16% 档只有 5 人 ⇒ 最多一组 48%，另一组最高 44%（16+16+12）。

**两段都可能起作用。** A 班的休息窗 `[班长, 24]` 会**跨过中枢的换班边界**：边界之前吃 A 组的加成、之后吃 B 组的，按时间累加（§4.4）。B 班的休息窗 `[0, 班长]` 同理。

所以**不存在「哪一组必须强」这种固定规则**，只有一个总判据：

```text
每个班次：R = Σ_k v_k·Δt_k ≥ C
```

而「中枢需要多强」取决于**班长有多长**——班长越长，耗得越多、休息窗越短、要求越高（§6.6 的对照表）。本方案里中枢 B 段恰好落在所有 A 班的休息窗内，所以它对 A 班的贡献是决定性的；但换一组班长，A 段完全可能承担主要份额。

| 本方案取值 | 名单 | `u` | `v` |
|---|---|---|---|
| 中枢 A 段（0–14） | 阿列什（12%，β 封顶） | 12% | **13.44%** |
| 中枢 B 段（14–24） | 黎风 + 梨诺 + 大潘（各 16%） | 48% | **17.76%** |

> 中枢没有心情减免技能 ⇒ `d = 7.2%/h` 恒定 ⇒ **连续在岗上限 `1/0.072 = 13.889 h`**，超出则该段 `u = 0`；红脸后要 `1/0.12 = 8.333 h` 回满。

### 4.4 稳定性判据

**两班**：每个班次都要能回满

```text
R = Σ_k v_k · Δt_k        C = min(1, d·h)
稳定 ⟺ R ≥ C            # R = C（余量 0）算稳定
```

**单班**：没有 B 组接班，靠“红脸后回满”循环（周期不整除 24，允许相位漂移，见 §5.2）

```text
周期 = 1/d + t满
```

**不稳定方案怎么算**（决定“能不能用”的核心）

若 `R < C`，方案不会第一天就崩：第一天满心情开工，之后每天的开工心情 = 昨日结余 + 休息窗恢复量，能干的时长 = `开工心情 / d`，干到班长就红脸离岗。红脸当天离岗后休息窗变长，恢复量也随之变大——所以**不能**再用“每天只回得起 `R`”来算。

长期平均工作时长有闭式：

```text
稳定的日产出   = E × min(班长, 1/d)                        # R ≥ C，可逐日重复；乘 E，不乘速率
v̄    = (Σ_k v_k·Δt_k) / (24 − 班长)                       # 休息窗内的加权平均回复速度
W*   = 24·v̄ / (d + v̄)                                     # 衰减时长期平均每天能干多久
不稳定的长期值 = E_A × min(班长, W*) + E_B × (24 − 班长)     # 不撞 100% 上限时成立
判定：两者取高
```

- `v̄` 必须是**休息窗内的加权平均**：休息窗跨中枢两段时（§4.3），不能只取其中一段的 `v`，否则 `W*` 无定义。
- 上式的“不稳定长期值”隐含 **B 班本身不红脸**（`24 − 班长 ≤ 1/d_B`）。B 班也会红脸时，两班都要各算一次衰减，不能直接相加。

`班长 > W*` 且恢复量会把心情冲到 100% 以上时，截断会作废一部分恢复，长期值**低于**闭式，只能逐日模拟（例：`W* = 17.87` 时 `h = 19` 只比 `W*` 大 1.13 h，1200 天里已有 300 天撞上限）。

| 情况 | 取哪个 |
|---|---|
| 不稳定的长期值 < 降级后的稳定值 | **降级** |
| 不稳定的长期值 > 降级后的稳定值 | **不降级**，接受衰减 |

这里的“长期值”一律指**逐日推进到稳态后的平均值**，不是首日、也不是前几天的最高值（详见 §6.7 的判定）。

当 `E_A > E_B` 时，两班制只需要在 `⌊W*⌋` 和 `⌊W*⌋+1` 之间选，判据可化简成一次比较：

```text
E_A × (W* − ⌊W*⌋) > E_B   ⇒   (⌊W*⌋+1) 班优于 ⌊W*⌋ 稳定班
前提：E_A > E_B 且 ⌊W*⌋ ≥ 1
```

> `E_A > E_B` 是必须的前提：否则班长越短 B 班越吃香，最优稳定班长不一定是 `⌊W*⌋`。
> `W* < 1` 时 `⌊W*⌋ = 0` 不是合法班长（`h ∈ 1..23`），此时只能排 `h = 1` 或转单班，不能套用上面的化简式。

> 例：制造舱在中枢只有 12%、B 班是 3 名白板时 `W* = 17.87`：18/6 长期 87.91 > 17/7 稳定 86.46，且 18/6 是全部班长里的最大值 ⇒ **不降级**（`4.18 × 0.872 = 3.65 > 2.20`）。
> 反例：`W*` 的小数部分很小、B 班又不弱时（会客室那组：`4.18 × 0.228 = 0.95 < 2.86`）⇒ 必须降级。
> **降不降级只由效率决定，不由优先级决定**——会客室自己也可以被降级。完整算例见 `..\排班示例\帝江号制造舱衰退班次对比.md`。

**稳定性的两层口径（不要混用）**

上面那个 `R ≥ C` 是**狭义稳定**。它决定"这个班次怎么取值"，不决定"这个候选能不能选"。准入门槛是另一个东西：

| 层 | 定义 | 取值方式 | 是否准入 |
|---|---|---|---|
| **狭义稳定** | 该班次 `R ≥ C`：全程不红脸、下班回满 | 闭式：日产出 = `E × min(班长, 1/d)`，天天一样 | **不是**。它只是取值方式的一种 |
| **广义长期稳定** | 该方案在长周期上落进**有界统计稳态**：心情绕某个不动点摆动、日产出在闭区间内来回、长期均值不漂移（不要求回满，也不要求日产出进固定循环） | 长周期均值（逐日推进到稳态后取平均，见下条） | **是**。长期均值还在漂的方案没有可比的"长期值"，必须判为不可用 |

"广义长期稳定"的判定（逐日模拟的两级口径）：

```text
① 一级：心情状态出现精确循环      ⇒ 取该循环的平均值；
② 二级：没有精确循环            ⇒ 把统计窗对半切，要求前后两半均值之差的相对量 ≤ 1e-4
                                  （含义：均值不漂移；允许日产出在区间内摆动，不要求进固定循环）；
③ 一级二级都不满足              ⇒ 该候选判为"不可用"（不管首日/前几天的值多高）。
```

> 两个层级的实例（同一份示例文档）：
> **17/7** 属于狭义稳定——`R ≥ C`、开工心情天天 100%、天天 86.46；
> **18/6** 不属于狭义稳定，但属于广义长期稳定——开工心情在 80.64%~87.36% 之间摆、日产出在 86.35~88.44 之间摆、"第 9 天之后产出每天都不一样"（没有固定循环），长期均值 **87.91**。
> 两者用同一个尺度比较 ⇒ 18/6 胜出。**最低那天 86.35 低于 17/7 的 86.46 也不影响结论**，比的是长期均值。

### 4.5 回满需时

```text
t满 = min{ t : Σ_k v_k·Δt_k ≥ C }
余量 = 休息小时 − t满
```

按时间先后累积，达到缺失量即停（回满不储存）：

```
回满需时(C, 窗口, u(t)):
    t ← 0; need ← C
    for 中枢阶段 k in 覆盖窗口的阶段(按时间顺序):
        dt ← overlap(窗口, k);  v_k ← 0.12 × (1 + u_k)     # 红脸段 u_k = 0
        if need ≤ v_k × dt: return t + need / v_k
        need ← need − v_k × dt;  t ← t + dt
    return ∞                          # 回不满
```

### 4.6 心情是每人一条（何时可以合并）

心情状态**本质上是每个在岗干员一条曲线**。默认口径能合并成一个数，靠的是两条前提：

```text
① 同班共用同一个 d（d 由在岗者的减免之和决定，本来就按整班算）
② 没有任何人被单独补过心情
```

两条同时成立时，同班各人的起点、斜率、休息窗全相同 ⇒ **完全重合**，合并是恒等变形，不是近似（§4.2 的“同组人同时红脸”就是这条的推论）。

打破前提的情况只有一种：**中枢助力**把心情点数只发给其中 1–2 人。此时曲线不再重合，某人先红脸时班组不空，倍率要按实际在岗人数重算。

**分人后倍率与心情消耗都要重算**（以会客室 A 组三人、每人 30% 收集 + 18% 减免为例）：

| 实际在岗 | 人数项 | 加成 `b` | 倍率 `E` | 减免 `r` | 心情消耗 `d` |
|---|---|---|---|---|---|
| 3 人 | `1 + 0.40×3 = 2.2` | 90% | **4.18** | 54% | 3.312%/h |
| 2 人 | `1 + 0.40×2 = 1.8` | 60% | **2.88** | 36% | 4.608%/h |
| 1 人 | `1 + 0.40×1 = 1.4` | 30% | **1.82** | 18% | 5.904%/h |

> 走掉的人带走了自己的减免技能 ⇒ **留下的人心情消耗变快**。只改倍率、不改 `d` 是错的。

> 助力的具体口径与阈值算例见 `帝江号会客室信用计算逻辑.md` §8；开关默认**关闭**，关闭时全文只用合并口径。

## 5. 班次模式

### 5.1 两班

```text
h_B = 24 − h_A            # h_A 取整数 1..23
Y日 = E_A·H_A + E_B·H_B
约束：两班各 ≥1 人（人数 1..工位数）；两组人员互斥；
      各自按 §4.4 取值（狭义稳定用日产出，衰减用长周期均值，且须满足广义长期稳定）
```

### 5.2 单班

```text
周期 = 1/d + t满
Y日  = E · (1/d) · 24 / 周期
在岗占比 = (1/d) / 周期
```

周期通常不是 24 的整数倍 ⇒ 单班产出是**归一到 24 h 的长期平均**，不保证每天相同。

### 5.3 两班 vs 单班（制造1，A 组 `b=90% / r=36%`，`E=4.18`）

| 模式 | 计算 | 日产出 |
|---|---|---|
| 两班（19/5，B 组 `b=60%`） | `4.18×19 + 3.52×5` | **97.02** |
| 两班（19/5，B 组只有白板 `b=0`） | `4.18×19 + 2.2×5` | **90.42** |
| 单班（中枢 14/10：A 段 12%、B 段 48%） | 见下 | **76.65** |

单班那一行必须**分段**算回满（中枢 A 段 12% ⇒ `v = 13.44%`，B 段 48% ⇒ `v = 17.76%`）：

```text
在岗 1/d = 1/4.608% = 21.7014 h（0:00–21.7014 在岗）
回满 6.7016 h = 2.2986 h × 17.76%(21.7014–24，中枢 B 段) + 4.4030 h × 13.44%(次日 0–4.4030，中枢 A 段)
             = 0.4082 + 0.5918 = 1.0000 ✔
周期 = 21.7014 + 6.7016 = 28.4030 h
日产出 = 4.18 × 21.7014 × 24 / 28.4030 = 76.65
```

> 若硬把中枢当成全天 48%（`v = 17.76%`），会得到回满 5.63 h、周期 27.33、日产 **79.66**——但那要求中枢全天满编，实际排不出来。这就是“休息窗跨中枢边界要分段累加”的直接后果。

**能开两班就开两班**：即使 B 班只能放白板，两班仍比单班高 `90.42 vs 76.65`（+18.0%）。只有**连 3 个白板都凑不出**（第二组无人可放）时才转单班。

## 6. 求解

### 6.1 目标：按**产物类别**的字典序

```text
max 线索（会客室）≻ 干员经验（所有产它的制造舱合计）≻ 武器经验（合计）≻ 培养舱（9 槽合计）
```

**比较的单位是「产物类别」，不是「设施」。**

同一类别由多个设施生产时（例如两座制造舱都产干员经验），它们是一个**整体**：把它们的合计产量一起最大化，不存在"谁先谁后"。两个舱各自该用几分加成、各自几点换班，都由这个合计值决定。

中枢没有产出，只决定可行域，不参与比较。前一级吃满才轮到下一级。

> **反例说明为什么必须按类别。** 干员经验池（缺卡缪）= 4 个 30% 档（莱万汀、庄方宜、余烬、噗切娜）+ 2 个 20% 档（狼卫、赛希）：
>
> - **按设施逐个排**：制造1 先拿自己的最优配置 `(90%, 36%)` ⇒ `4.18×19 + 2.2×5 = 90.420`；制造2 只剩 `(70%, 0%)` ⇒ `h* = 14`，`3.74×13.8889 + 2.2×10 = 73.944`。合计 **164.364**。
> - **按类别联合枚举**：把 6 人重新分给两舱，最优是两舱都拿 `r = 18%`、`h* = 17` ⇒ `2.2 × [(1.9+1.7)×16.9377 + (1+1)×7] = 164.946`。
>
> 差 **0.582**（+0.35%）。差额大小取决于池子的档位分布，但方向是确定的：**逐设施贪心不会优于同类联合**。完整枚举见 `..\排班示例\帝江号排班_缺卡缪_双制造舱干员经验_9晶植.md` §4.3。

### 6.2 变量与层级

| 层级 | 变量 | 说明 |
|---|---|---|
| **全船唯一** | 中枢配置 `(h_中枢, A 组, B 组)` | 它定义时间轴与 `u(t)`，四个设施共用同一条 |
| 每设施独立 | 模式（两班/单班）、`h_f`、A 组、B 组 | 互不影响，只受“人员唯一”约束 |

> **时间轴只有一条。** 设施的 `h_f` 各自独立，但它们看到的 `u(t)` 必须来自同一个中枢配置——不能出现“会客室按 20:00 算、制造舱按 14:00 算、中枢各配各的”。

### 6.3 约束

1. 每人每天仅一段工作（跨设施唯一）。
2. 两班模式下每班 ≥ 1 人。
3. 每个班次按 §4.4 的**两层口径**取值（用同一条 `u(t)` 分段计算）：狭义稳定（`R ≥ C`）的用日产出；衰减的用长周期均值，且必须满足广义长期稳定，否则该候选不可用。
4. 中枢白板贡献为 0；其他设施白板贡献 `+40%`。
5. **助力默认关闭**。开启后总点数 `a ≤ 2`，按 会客室 → 干员经验制造 → 武器经验制造 → 培养舱 的顺序分配。顺序本身就是判据：**按字典序，不做跨类别的数值比较**（`§1` 已规定只比较同种产物）——会客室只要还有正收益就继续吃，吃到边际收益为 0 才轮到下一站。
   分配必须按**整组**评估，不能逐点贪心：会客室 1 点单独用毫无收益（撑不住任何人），2 点一起才解锁 21/3。详见 `帝江号会客室信用计算逻辑.md` §8。
   两种硬约束必须同时满足：两点给**两名不同干员**；目标心情 **≤70%**（否则溢出作废）。
6. **白板（补位）挑人规则**：补位只从"不占用任何技能岗/中枢、且对本设施无加成、无减免"的干员里取（§6.5 第 3–4 步的人数不足部分由它填）。
   挑人按**牺牲顺序**——培养舱 → 武器经验制造舱 → 干员经验制造舱 → 会客室：先拿"对低优先级设施才有用"的人去顶，把有用的人留给更难排的设施；同一设施内按 `charId` 升序取。
   **这只是「基准序」，不是最终裁决。** 补位对本设施产出无影响、对**后续类别**有影响，所以"烧掉谁"是候选维度（`补位变体`）：基准序给出默认解，换不换人由 §6.8 与下游产出决定。
   > 反例：会客室没有线索技能 ⇒ 全靠白板 ⇒ 按基准序把武器经验的主力当白板烧掉，武器经验 `40.63 → 42.59`。
7. **班次人数下限**：两班模式 `N_A ≥ 1` 且 `N_B ≥ 1`；单班模式 `N_A ≥ 1`。**不允许 0 人班次**；`N < 工位数` 是合法候选（§6.7「减少人数」），不是缺人。

### 6.4 算法：字典序分支定界

**外层枚举时间轴，内层排人**。这样中枢配置只落地一次，不会出现“每个设施各用一套时间轴”的错误。

```text
# ⓪ 预备（**可选诊断，不属于算法**）：
#    按"不受中枢限制"（假设全天 v = 17.76%）跑一遍各设施的独立最优，
#    得到每个干员的最好用途与日产出增量 = 该干员的「机会成本」。
#    同分裁决已压成两级（§6.8），**机会成本不参与裁决**；它只能作为可选的诊断输出。

# ① 外层：枚举中枢配置（= 枚举时间轴）
for 中枢配置 C0 in 全部(中枢 h ∈ 1..23, A组, B组):
    按 §6.6 的强度表判断这条时间轴下各设施的班长上限（不可行性判断，**不用它剪枝**：
    这个界只由"满池最好班组 × 最大可用工时"决定、与时间轴无关，区分不了强弱中枢）

    S ← { C0, 剩余助力点数 = 2 }             # 每条分支都带同一个 C0 与一个剩余点数

    # ② 内层：按「产物类别」的顺序排，不是按设施
    for 类别 g in (线索, 干员经验, 武器经验, 培养产物):
        组 G ← g 名下的全部设施（例：干员经验 → {制造1, 制造2}）
        for s in S:
            V(s) ← max{ Σ_{f ∈ G} 产出(f, 候选_f) :
                        候选_f 取 f 的全部(模式, 班长, A组, B组, 用掉 k 点助力)，
                        **同组设施联合枚举**，
                        满足 每人唯一 / 每班≥1人 / 用 C0 判 §4.4 / Σk ≤ s.剩余点数 }
        L ← max over s of V(s)
        S ← { s ∪ 该组方案, 剩余点数 − Σk : V(s) == L }
        若 S 为空 → 按 §6.7 降级该组 → 仍为空 → 该类别记 0；
        且若该类别是最高优先级（线索），整条时间轴作废（会客室必然存在，不允许记 0）

    # ③ 这条时间轴下的各类别最优得分已确定
    记下 (C0, S)

# ④ 在所有中枢配置里取字典序得分最高的一组，作为最终布局
按 §6.8 同分裁决从该组的 S 中取一个输出
```

**候选空间（`候选_f` 到底是什么）**：`(模式, 班长, A 组, B 组)` 四元组，其中

- **模式** ∈ {两班, 单班}；两班时 `班长 h ∈ 1..23`，单班无班长；
- **A/B 组人数 = 该班实际在岗人数 `N`，取值 `1..工位数`**（`N` 就是 §0 的 `N`，白板也算人，见 §1）：
  工位没填满时先看"有没有白板可补"（补满工位的产出更高），补不齐就是 §6.7 的「减少人数」，
  `N < 工位数` 同样是合法候选；两班 `N_A ≥ 1 ∧ N_B ≥ 1`，单班 `N_A ≥ 1`；
- 组内顺序无关，按集合处理。

| 步骤 | 作用 |
|---|---|
| ① 外层循环 | 这就是「先试中枢几点换班」：23 种换班时刻 × 中枢两组名单，全部试过 |
| ② 内层循环 | 按**类别**排：同一类别的多个设施**一起分配人员**，只比它们的合计产量；每个设施仍各自枚举自己的班长 1..23 |
| §4.4 判据 | 不稳定的候选**不淘汰**，改记“长期值”；去留由同组合计比较决定（§6.7 准入线） |
| ③ 记录 | 排完得到 `(线索, 干员经验合计, 武器经验合计, 培养合计)` 四个数 |
| ④ 比较 | 字典序比较四元组，取最高的那条时间轴及其布局 |

> **同组设施必须联合枚举，不能逐个贪心。** 干员经验池（缺卡缪）里 4 个 30% 档 + 2 个 20% 档：逐个排得到 `90.420 + 73.944 = 164.364`；联合枚举得到“两舱都 `r=18%`、`h*=17`”，合计 **164.946**。

**为什么外层必须是中枢**

- 中枢是**唯一同时影响所有设施**的量（`u` 一掉，所有 A 班一起掉）；
- 中枢只有 23 种换班时刻，是最小的枚举维度；
- 不先固定它，就无法评估任何车间（评估车间要先知道回血速度，而回血速度来自中枢）。

**剪枝规则**

| 剪枝 | 做法 |
|---|---|
| 产出剪枝 | 本组产出 < 本级最优 `L` 的分支直接丢弃 |
| 人员集合去重 | 产出相同且**占用人员完全相同**的候选只留一个 |
| 上界剪枝 | 先算 §6.6 的强度表给出的可行性上界。**但它只用来判断"排不排得出"，不用来剪中枢**：这条界只由"满池最好班组 × 最大可用工时"决定、与时间轴无关，而中枢之间的差别恰恰只在时间轴上 |
| 值前缀剪枝 | 产出向量是字典序、下游类别只能追加 ⇒「本深度的前缀已**严格**劣于现任」时整棵子树剪掉。**只剪浅层**（深剪会把记忆化的收益抹掉），且被剪过的节点不写记忆化 |
| ~~中枢按需升级~~ | **不做**：中枢配置在外层完整枚举（23 × 两种分组）。贪心升档会漏掉“弱中枢 + 短班长”这类解 |
| **同组对称性** | 同一类别下若干座**完全同类**的设施互换身份不改变产量，只保留一种排列（例：两座制造舱谁叫“1 号”无关紧要） |

> 产出相同但**占用人员不同**的候选必须全部保留，否则会漏掉后续最优。
>
> 但"保留"不等于"一定能排出来"：候选的**值**可能很高、人选却凑不出来（两班要两组互不相交的人、白板不够、同一签名组里没有互斥的人选）。此时必须按**值档从高到低**退到第一个真能实现的档，再把该类别的得分定在这一档；**不能**因为最优档排不出来就把整个类别记 0。

### 6.5 候选的枚举与判定顺序

对某个设施，候选按下列顺序生成与筛选：

```text
1. 选模式：先试「两班」，再试「单班」
2. 两班：班长 h = 1..23；单班：无班长
3. 选 A 组的干员组合（从剩余池里选，人数 `N_A = 1..工位数`；满工位时缺的人用白板补满）
4. 选 B 组的干员组合（两班时；从 A 组之外选，人数 `N_B = 1..工位数`）
5. 判「每班 ≥ 1 人」
6. 判「每人唯一」（与已锁定设施不冲突）
7. 判 §4.4：能稳定 ⇒ 记稳定日产出；不能稳定 ⇒ 记**长期值**（不丢弃）
8. 通过 → 该候选带着「稳定值或长期值」进入同组竞争
```

> 第 7 步**不丢弃**任何候选，只是把它的取值换成“稳定值”或“长期值”。丢弃发生在同组竞争（比合计）之后，由 §6.7 的判据决定——**淘汰一个候选的是产出比较，不是稳定性本身**。

### 6.6 中枢：强度需求与空窗判据

**中枢择优不单设规则。** 中枢配置和其他候选一样进 §6.4 的字典序比较，同分时用 §6.8 裁决——不存在“先验地选一个最小中枢”的独立规则。

本节只回答两件事：给定了各设施班长，中枢**至少要多强**（供上界剪枝与可行性判断）；以及中枢自己会不会红脸。

**中枢需要多强：由班长长度决定，不是由“谁先接班”决定**

唯一的判据是 `R ≥ C`，其中 `R` 按中枢边界分段累加。所以「中枢够不够」等价于「晚间的平均回复够不够」，而这完全取决于各设施的班长：

```text
需要的平均回复 = C / 休息小时 = (d × 班长) / (24 − 班长)
需要的 u       = 需要的平均回复 / 0.12 − 1        # 负数表示 12% 基础回复就够
```

以三个主力舱为例（制造1 `r=36%`、培养舱 `r=18%`、会客室 `r=54%`）：

| 设施 | 班长 | 消耗 `C` | 休息 | 需要的平均回复 | 需要的 `u` | 判定 |
|---|---|---|---|---|---|---|
| 制造1 | 17 h | 78.34% | 7 h | 11.19% | 0（基础 12% 就够） | 无需中枢 |
| 制造1 | 18 h | 82.94% | 6 h | 13.82% | **15.2%** | 一个 16% 档即可 |
| 制造1 | **19 h** | 87.55% | 5 h | **17.51%** | **45.9%** | 必须三人全 16% |
| 制造1 | 20 h | 92.16% | 4 h | 23.04% | 92% | 不可能 |
| 培养舱 | 16 h | 94.46% | 8 h | 11.81% | 0 | 无需中枢 |
| 培养舱 | **17 h** | 100% | 7 h | **14.29%** | **19.0%** | 两个 16% 档 |
| 会客室 | 18 h | 59.62% | 6 h | 9.94% | 0 | 无需中枢 |
| 会客室 | **20 h** | 66.24% | 4 h | **16.56%** | **38.0%** | 三人全 16% 或 16+16+12 |

**怎么用这张表**：把各设施的实际班长代进去，取**同一时段内最紧的那个**，就是中枢该段的强度需求。

- 若 制造1=19、培养=17、会客=20 ⇒ 晚间需求 = `max(45.9, 19.0, 38.0) = 45.9%`
- 若把制造1 缩到 18 ⇒ 需求降到 `max(15.2, 19.0, 38.0) = 38.0%`（会客室变成瓶颈）
- 若会客室也缩到 19 ⇒ 需求降到 `max(15.2, 19.0, 4.9) = 19.0%`（培养舱成为瓶颈）

**这就是"中枢强度不是硬规则、而是算出来"的含义**：把班长缩一点，中枢就能省下两个 16% 档的干员还给培养舱——这个交换值不值，由产量算出来。

中枢各段在岗人数对应的回复强度：

| 中枢某段在岗 | `u` | `v` | 5 h 休息窗能回 | 制造1A（19 h）需要 |
|---|---|---|---|---|
| 三人 16×3 | 48% | 17.76% | 88.80% | 87.55% ✔ 余量 4 分 13 秒 |
| 两人 16+16 | 32% | 15.84% | 79.20% | ✘ |
| 一人 16 | 16% | 13.92% | 69.60% | ✘ |
| 无人 / 白板 | 0 | 12.00% | 60.00% | ✘ |

**补人来源顺序**：① 剩余池 → ② 降级最后分配的设施 → ③ 记缺口。

**中枢自己也是一个班次，必须自己稳定**

中枢没有心情减免 ⇒ `d = 7.2%/h` 恒定。所以中枢的两段要各自满足 §4.4：

```text
C_段 = min(1, 7.2% × 段长)
R_段 = 该段干员自己休息窗内的恢复量（按当时生效的 u(t) 分段）
稳定 ⟺ R_段 ≥ C_段
```

**中枢红脸空窗**（整点换班带来的必然问题）

中枢连续在岗上限 `1/0.072 = 13.889 h`，而换班只能整点：

| 中枢段长度 | 段内 `u` 的情况 | 处理 |
|---|---|---|
| ≤ 13 h | 全程有 `u` | 可直接用整段的单一 `v` |
| 13–14 h | 末 `段长 − 13.889` 小时 `u = 0` | 该段内要**再分一段**：前 13.889 h 用 `v = 12%(1+u)`，之后用 `v = 12%` |
| > 14 h | 空窗更长 | 同上，且通常不划算 |

```text
判据（两段都要查，B 段可达 23 h）：
  ① 中枢该段自己 R_段 ≥ C_段
  ② 被它服务的班次，R 按上面的分段重新累加，仍满足 §4.4
两条都过才可用；任一不过 ⇒ 缩短该段，或调整对应设施的班长
```

> **不能**用“被服务班次的 `t满` ≤ 13.889 h”当判据：那两个量的起点不同（`t满` 从休息窗起点算，13.889 从段起点算），且它只查了服务方、没查中枢自己。反例：`h_中枢 = 23` 时 A 段消耗已封顶 100%、休息窗只有 1 h，`R_段 ≈ 13%`，中枢必然红脸，但上面的旧判据会放过它。

**中枢候选怎么归并**

中枢配置的枚举量是"23 种换班 × 两组名单"，直接当候选会爆炸。两条约定：

```text
① 归并：同一 (uA, uB) 组合只保留一条——"占走这些人时机会成本最低"的那组替补
        （谁去补位不影响 u，只影响别的设施能用谁）；
② 支配：人数不更多、且两段 u 都不更低的候选，可以剪掉。
        注意这条在"每班恰好 3 人"的模型下几乎剪不动：所有中枢候选都恰好占 6 个人，
        「集合包含」退化成「集合相等」，所以真正起作用的是 ①。
```

> 归并只改"这条时间轴占的是谁"，不改 `u(t)`，所以不影响产出计算的正确性；它带来的近似风险登记在 `tools/README.md` §5.1 的假设台账里。

### 6.7 降级动作集

一个设施的候选 = 两班模式（`h ∈ 1..23`）× 单班模式 × 每班人数（`1..工位数`）× 每个签名组，全部候选**同尺度**比较后取最高者。所谓"降级动作"不是"排不出稳定方案时才启用的后手"，而是候选空间本来就包含的那几类取值：

| 动作 | 具体做法 | 代价 |
|---|---|---|
| **缩短班长** | 枚举 `h' ∈ 1..h−1` 全算一遍，按 §4.4 取长期值最高的 `h'` | 直接损失 `H` |
| **减少人数** | 把某班人数从工位数 `s` 降到 `n`（`1 ≤ n < s`）：人数项 `(1+0.40n)` 与加成一起按**实际班组**算 | 每少 1 人约 `−0.40 / (1+0.40n)` |
| **降低档位** | 把 30% 档换成 20% 档（`b` 下降） | 约 −5%~−10% |
| **转单班** | 模式改单班，省下一整组人 | 示例：`90.42 → 76.65`（−15.2%） |

**减少人数补充规则**（§6.3 第 7 条的人数下限在这里落地）：

```text
· 人数取值 n = 1..工位数；两班 n_A ≥ 1 且 n_B ≥ 1；单班 n_A ≥ 1；不允许 0 人班次。
· 减少人数**始终在候选空间里**，不需要"稳定方案排不出来"这个前提。
· 唯一的剪枝是**可证支配**：本类别可用干员数 ≥ Σ(2 × 工位数) 时，
  任何 n < 工位数 的候选都能靠"往空工位塞一个尚未被用到的白板"严格变好
  （E = (1+0.40n)(1+b) 随 n 严格增，而 d 只按设施算、与人数无关），
  所以这些候选被支配、可以合法剪掉；人手不足时自动展开 1..工位数。
```

单个动作都不够时，按 缩短班长 → 减少人数 → 降低档位 → 转单班 的顺序**叠加**，最多叠两项。

牺牲顺序（从低优先级开始让）：培养舱 → 制造舱（武器经验那舱先让）→ 制造舱（干员经验那舱）→ 会客室。**任何设施都可以用这四种动作，包括会客室自己**——它没有更低优先级可让时只能自救。

**准入线**（与 §4.4 的两层口径一致）：

```text
① 准入门槛只有一条：广义长期稳定（长周期均值收敛、不漂移，§4.4）。
   长期均值还在漂的候选直接判"不可用"，不管它首日/前几天的值多高。
② 在"可用"的候选里，按长期值（狭义稳定的班次就是它的日产出）同尺度比较，取最高者。
   不设"先找稳定解、稳定解存在就不比衰减班"的顺序——狭义稳定不是准入门槛。
```

> 这条准入线就是“衰退班可以采纳，但必须是长期平均真的更高”的落地。制造舱 18/6 是正例（长期 87.91 > 稳定 86.46）；只高一天的两天值不构成理由。
> 反例提醒：19/5 首日 90.42 比 18/6 的首日还高，但长期值只有 84.62 ⇒ 必须判负。比的是长期均值，不是任何一天。

### 6.8 同分裁决

产出完全相同时，只按两级决定，之后**不再比较任何东西**：

1. **占用干员更少**：整份布局占用的人数更少者胜；
2. **人数相同**：取搜索过程中**先遇到**的那一个。

```text
同一产出向量下的取舍：人数少 ⇒ 先遇到
不参与比较的量：中枢需求、班长、charId、占用串
```

**为什么砍掉后面几级**：它们只在"产量相同、人数相同"时起作用，那时已经不改变任何产出；保留它们只会迫使搜索留下大量"换了人、产量不变"的等价候选。代价是输出的唯一性来自**遍历顺序**而不是 `charId`：同一份代码、同一份数据稳定，换了遍历顺序就可能换人（产量不变）。

### 6.9 输出内容

| 项 | 内容 |
|---|---|
| **搜索状态** | 搜索跑完没有：`跑完` / 节点或时间预算耗尽 / 有候选不收敛 / 启用了近似。**不输出"是不是最优"**——工具只算它能在候选空间里算到的最优解，不声称全局最优 |
| **类别汇总** | 线索（张/信用）、干员经验（合计等效小时/件数/经验）、武器经验（合计）、培养产物（合计批/件） |
| **设施明细** | 每个设施：模式、换班时刻、两组名单（含白板）、每班实际人数、自己的等效小时 |
| 中枢 | 换班时刻 + 两组名单；每段的红脸时刻与空窗是否安全 |
| 心情 | 每班次的 `C`、`R`、`t满`、余量 |
| 稳定性 | 每班次是狭义稳定还是衰减；衰减的班次标注"长期值由模拟算出" |
| **衰减班启用说明** | 一旦有班次取衰减形态，必须写明它是靠长期值取胜的：`<设施> h/…，长期值 X > 同组稳定最佳 Y（+Z）` |
| **助力**（开关打开时） | 每天 `a` 点发给谁、注入时刻区间（绝对时刻 + “心情 ≤70%”条件）、给全船带来的增量 |
| **练度建议** | 只针对**已有干员**：每个干员的每个技能「升一档」能带来多少全船增量，按增量排序。不输出获取新干员的建议 |
| 缺口 | 降级后仍不可行的设施差在哪（差几名干员 / 差哪个档位 / 班长最多几小时） |

> 两个粒度都要：**类别汇总**回答"我一天总共拿到多少干员经验"，**设施明细**回答"哪个舱放谁、几点换班"。练度建议需额外输入每个技能的**当前档位**（α/β/γ）；本文主算按最高档。

### 6.10 一次完整走查（残局：缺卡缪，双制造舱都产干员经验）

```text
中枢配置 C0 = (h=14, A组=阿列什 12%, B组=黎风+梨诺+大潘 各16%)
   ↓ u(t)：[0,14) → 12%（v=13.44%）；[14,24] → 48%（v=17.76%）

② 线索（会客室）：20/4
     A 组 洛茜+艾尔黛拉+祀（收集 90%、减免 54%）→ E=4.18、d=3.312%
     B 组 埃特拉(30%)+秋栗+卡契尔（减免 18%）→ E=2.86、d=5.904%
     A 班 C=66.24%，休息 [20,24] 全在 B 段 → R=4×17.76%=71.04% ✔
     B 班 C=23.616%，休息 [0,20] 跨段 → R=14×13.44%+6×17.76%=294.72% ✔
     产出 = 4.18×20 + 2.86×4 = 83.60 + 11.44 = 95.04 → 锁定

③ 干员经验（制造1 + 制造2 **联合枚举**）：
     池子 = 4 个 30%（莱万汀、庄方宜、余烬、噗切娜）+ 2 个 20%（狼卫、赛希）
     3+3 的分法共 10 种，全部试算 ⇒ 最优 6 种等价（两舱 r 都是 18%、h* 都是 17）
     舱甲：A 莱万汀+余烬+噗切娜（90%、18%）→ E=4.18、d=5.904%、H=16.9377
           B 3 白板 → E=2.2         → 4.18×16.9377 + 2.2×7 = 70.799 + 15.400 = 86.199
     舱乙：A 庄方宜+狼卫+赛希（70%、18%）→ E=3.74、d=5.904%、H=16.9377
           B 3 白板 → E=2.2         → 3.74×16.9377 + 2.2×7 = 63.347 + 15.400 = 78.747
     合计 164.946 → 锁定
     （逐个贪心只能到 164.364，见 §6.1）

④ 武器经验：两舱都产干员经验 ⇒ 本类别无设施，记 0

⑤ 培养产物（晶植 9 槽）：17/7
     A 别礼+汤汤+诀（90%、18%）→ E=4.18、d=5.904%、H=16.9377
     B 伊冯+安塔尔+陈千语（0%、36%）→ E=2.2
     单槽 = 4.18×16.9377 + 2.2×7 = 86.199；9 槽 = 86.199×9 = 775.795 → 锁定

⑥ 记录得分 (95.04, 164.946, 0, 775.795)
   ↓ 换下一个中枢配置，重复 ②–⑥
⑦ 全部中枢配置比完，取字典序最高的一组输出

全船 = 95.04 + 164.946 + 775.795 = 1035.781 等效小时/日
```

> 三个要点：
> 1. **同组设施联合枚举**：逐个排只有 164.364，联合枚举 164.946。
> 2. **`h = 17` 不是随便取的**：`r = 18%` 把 `1/d` 定死在 `16.9377 h`，多排的 1 h 里有 `0.0623 h` 是红脸离岗，但比缩到 16 h 仍划算（`h=16` 只有 84.480）。
> 3. **赛希该去哪一舱**：不是固定放 2 号舱，而是“放到 B 班更长的那一舱”。本方案两舱 B 班都是 7 h，所以放哪舱都一样（这就是那 6 种等价解）。

## 7. 技能取值

| 规则 | 内容 |
|---|---|
| 同配方内加算 | 不同干员的适用数值技能相加后进入 `b`（或 `r`） |
| 跨配方隔离 | 晶植不计入矿物/菌类；武器经验不计入干员经验 |
| 覆盖不累加 | 同一技能按新档覆盖旧档 |
| 线索概率不进速率 | 只决定线索倾向 |
| 练度取最高要求 | 同岗需要多种技能时取更高的精英化 |
| 「仅进驻」 | 只用人数项的岗位不依赖该角色练度 |

## 8. 一页速查

```text
速率 = (100 + 40×在岗人数) × (1 + Σ技能加成)     # 进度/秒；中枢无人数项
倍率 = 速率 / 100
d    = 0.072(1 − r)                # 中枢恒 7.2%（无减免技能）
v    = 0.12(1 + u)                 # 按中枢分段；红脸段 u = 0，退回 12%
H    = min(h, 起点心情/d)           # 满心情时 = min(h, 1/d)；红脸即离岗，离岗起按 v 恢复
Y    = E·H
Y日  = E_A·H_A + E_B·H_B           # 两班
周期 = 1/d + t满；Y日 = E·(1/d)·24/周期   # 单班，允许不整除 24
R    = Σ v_k·Δt_k
稳定（狭义）：R ≥ C（R=C 也算稳定），日产出 = E·min(h, 1/d)
v̄    = (Σ v_k·Δt_k)/(24−h)         # 休息窗内的加权平均回复速度
W*   = 24·v̄/(d+v̄)                 # R < C 时长期平均每天能干多久
不稳定：长期值 = E_A·min(h, W*) + E_B·(24−h)   # 撞 100% 上限则须逐日模拟
判据化简：E_A·(W*−⌊W*⌋) > E_B ⇒ (⌊W*⌋+1) 班更优（需 E_A>E_B、⌊W*⌋≥1）
"长期值"一律指逐日推进到稳态后的平均值，不是首日
准入：只要"广义长期稳定"（均值收敛、不漂移）；狭义稳定 R ≥ C 不是准入门槛
候选：模式 × h(1..23) × 每班人数(1..工位数) × 签名组；n < 工位数 也合法，不允许 0 人班
同分裁决：只有两级 —— 占用人数更少者胜；人数相同取"先遇到的"（见 docs/adr/0002）
搜索状态：只报"跑完 / 预算耗尽 / 有不收敛候选 / 用了近似"，**工具不声称最优**
补位：基准序只是默认解，"烧掉谁"是候选维度（补位变体，见 GLOSSARY）
中枢需要多强：由班长长度决定（制造1 排 19h 才需要 45.9%；排 17h 时基础 12% 就够）
中枢的 R 按「中枢换班边界」分段累加：休息窗跨段时，前后分别吃两段的加成
中枢段长 > 13.889 h 会出现 u=0 空窗：段内要再分一段（前 13.889 h 用 v，之后退回 12%）
中枢两段必须各自满足 R ≥ C（中枢 d 恒 7.2%），B 段可达 23 h，两段都要查
时间轴只有一条：中枢配置在外层枚举（不做贪心升档），设施的 h 在内层各自枚举
单件耗时 = 进度上限 / (360000 × 倍率)   # 培养 125h、认知载体 24.4444h、线索 24.4444h
心情：默认每人一条；同班共用 d 且无人被单独补心情 ⇒ 合并成一个数（§4.6）
助力（默认关）：2 点/天、1 点 = 单干员 +30% 心情（目标须 ≤70%，两点给不同人）
助力阈值：会客室要 2 点才从 95.04 提到 96.36；1 点单独用无收益
助力顺延：会客室 → 干员经验制造 → 武器经验制造 → 培养舱（按字典序，不做跨类数值比较）
助力窗口：04:00 刷新、当天用掉；注入时刻只要目标心情 ≤70%，早用晚用等价
```
