# 帝江号会客室信用计算逻辑

> 本文只算一条产出线：会客室在岗干员自行收集的线索 × 20 信用。线索概率技能不进产量，只影响出哪种线索。
> 心情闭环的通用口径（`R ≥ C`、中枢 `u(t)` 分段、红脸与返岗）见 `帝江号排班与产出计算逻辑.md` §4。

## 0. 术语

| 术语 | 含义 |
|---|---|
| 一张线索 | 收集满 `8,800,000` 进度为一张。100% 速率下 **24.4444 h** |
| 等效小时 | 该班次推进的量（以 100% 速率的小时计） |
| 张数 | 该班次收了几张（连续值，可跨班累加） |
| 信用 | 张数 × 20 |

## 1. 变量与常数

| 变量 | 符号 | 含义 |
|---|---|---|
| 收集加成 | `b` | 在岗者线索收集效率之和（30% / 20%） |
| 减免 | `r` | 在岗者心情消耗降低之和（18% / 14%） |
| 在岗人数 | `N` | Lv3 = 3，缺人时见 §5 |
| 倍率 | `E` | `E = (1 + 0.40N)(1 + b)`，与总规范一致 |
| 心情消耗 | `d` | `d = 0.072 × (1 − r)`，每人每小时 |
| 班长 | `h` | 该班在岗小时数（整数 1..23） |
| 有效时长 | `H` | 真正在生产的时长，`H = min(h, 起点心情 / d)` |
| 本班消耗 / 可回复 | `C` / `R` | `C = min(1, d·h)`；`R` = 休息期能回的心情（按 `u(t)` 分段） |
| 回满 | `t满` | 从休息窗起点回满 `C` 所需小时 |
| 助力点数 | `a` | 每天可用 2 点，默认 0（§8） |

| 常数 | 值 | 出处 |
|---|---|---|
| 基础耗时 | **24.4444 h / 张** | `clueCollectPointMaxValue 8,800,000 ÷ 100 进度/秒 ÷ 3600` |
| 单张信用 | 20 | 每张线索兑换 20 信用 |
| 人数项系数 | 每人 +40% ⇒ 满编 `2.2` | `spaceshipGuestRoomCharAddPointIncrease = 40` |
| 基础心情消耗 | 0.072 / 小时 | `basePhysicalStrengthCostRate = 12/分钟` |

> 速率构成：`速率 = (100 + 40×人数) × (1 + Σ收集效率)`，单位进度/秒。满编 90% 时速率 `= 100 + 120 + 220×0.9 = 418` 进度/秒，`418/100 = 4.18` 即倍率。

## 2. 算式

```text
b         = Σ 线索收集效率
r         = Σ 心情消耗降低
E         = (1 + 0.40 × N) × (1 + b)               # 倍率
d         = 0.072 × (1 − r)                        # 心情消耗/小时
H         = min(h, 起点心情 / d)                    # 满心情时 = min(h, 1/d)
C         = min(1, d × h)                          # 本班消耗
R         = Σ v_k × Δt_k                           # 可回复，按中枢 u(t) 分段
稳定      = R ≥ C
不稳定    = 用总规范 §4.4 的长期值：E_A·min(h, W*) + E_B·(24−h)，W* = 24·v̄/(d+v̄)
            （撞 100% 上限时必须逐日模拟；且长期值 > 稳定值才允许采用）

单张耗时  = 24.4444 / E
等效小时  = E × H
张数      = 等效小时 / 24.4444
信用      = 20 × 张数
单班模式  = 周期 = 1/d + t满；张数/日 = E·(1/d)·24 / (周期 × 24.4444)
```

- **红脸不是“原地停产”**：心情归零的那一刻人就离岗，并从那一刻起按 `v` 恢复（总规范 §4.2）。所以 `h > 1/d` 多出来的时间是**离岗休息**，会让第二天的恢复量变大——这正是 `W*` 公式成立的原因。
- **稳定性不是准入门槛**：`R < C` 的班次照样参与比较，只把取值换成长期值（总规范 §6.7 准入线）。本文件默认只算稳定班，需要算衰减班时按上面的“不稳定”一行处理。

线索概率技能只决定线索倾向，不进倍率；只有「线索收集效率」与「心情消耗降低」进公式。
**技能档位一律取该干员的最高档：有 γ 用 γ，没有 γ 取 β**（埃特拉等的会客技能封顶在 β/γ 不等，按实际最高档取数）。

> **心情是每人一条。** 默认三条曲线完全重合（同班共用 `d`、无人被单独补心情），所以能合并成一个数；一旦用助力把点数只发给其中 1–2 人，就必须拆开：先红脸者先离岗，倍率按实际在岗人数重算（3 人 4.18 / 2 人 2.88 / 1 人 1.82）。见 §8。
>
> 为什么会重合可以用 §2 的式子直接验证：三人 `d` 相同、休息窗相同、起点都是 100% ⇒ 轨迹完全相同。

## 3. 示例

A 组 = 洛茜 + 艾尔黛拉 + 祀（三人均 30% 收集 + 18% 减免，双槽同会客）；B 组 = 埃特拉（30%）+ 秋栗（18% 减免）+ 卡契尔（白板）。
中枢 **h = 14**：A 段 0–14（12%，`v = 13.44%`）、B 段 14–24（48%，`v = 17.76%`）。

| | A 班（20 h） | B 班（4 h） |
|---|---|---|
| 加成 / 减免 | 90% / 54% | 30% / 18% |
| 倍率 | `2.2 × 1.90 = 4.18` | `2.2 × 1.30 = 2.86` |
| 心情消耗 | 3.312% | 5.904% |
| 有效时长上限 `1/心情消耗` | 30.193 h | 16.938 h |
| 有效时长 | 20（未及上限） | 4 |
| 本班消耗 `C` | `3.312%×20 = 66.24%` | `5.904%×4 = 23.616%` |
| 可回复 `R` | 休息 [20,24] ⊂ B 段 ⇒ `4×17.76% = 71.04%` ✔ | 休息 [0,20] 跨段 ⇒ `14×13.44% + 6×17.76% = 294.72%` ✔ |
| 单张耗时 | `24.4444 / 4.18 = 5.8480 h` | `24.4444 / 2.86 = 8.5470 h` |
| 等效小时 | `4.18 × 20 = 83.60` | `2.86 × 4 = 11.44` |
| 张数 | `83.60 / 24.4444 = 3.4200` | `11.44 / 24.4444 = 0.4680` |
| 信用 | 68.40 | 9.36 |

```text
张数/日 = 3.4200 + 0.4680 = 3.8880
等效小时 = 95.04
信用/日 = 20 × 3.8880 = 77.76
```

> B 班的 4 h 远小于它的有效时长上限 16.938 h，所以 B 班**不会红脸**，`r` 在 B 班完全没用（见 §4）。

## 4. 减免的价值门槛

```text
需要的减免 = 1 − 1/(0.072 × 班长)
```

A 班 20 h 的门槛是 **30.56%**：

| 减免 | 心情消耗 | 有效时长上限 | 张数（A 班 20 h） |
|---|---|---|---|
| 18% | 5.904% | 16.938 h | 2.8963 |
| **36%** | 4.608% | 21.701 h | **3.4200**（撑满 20 h） |
| 54% | 3.312% | 30.193 h | 3.4200（与 36% 同值） |

> **0% 这一行不列**：A 班要拿 90% 加成只能上洛茜 / 艾尔黛拉 / 祀，而这三人各自带 18% 减免 ⇒ `r = 0` 在 A 班是**不可达**的组合（唯一无减免的埃特拉只有 30% 加成）。

**结论**：

- A 班 20 h 至少要 2 人各 18% 才不吃亏（36% 之后再加减免没有收益，因为 20 h 已经撑满）；
- **B 班只有 4 h，减免在 B 班没有任何产出价值**（`1/d = 16.938 h` 远大于 4 h，4 h 之内根本不会红脸）。把秋栗放 B 班只是**零成本占位**——她在别处没有更高用途时才这么排；若她在别处更值钱，换成白板对 B 班产出毫无影响。

## 5. 缺人与停产

- `N=2` → 人数项 1.8（产出 −18.2%），`N=1` → 1.4（−36.4%）。只有缺的是**不贡献技能的占位**时才只有这一项损失。
- `h > 1/d` 的部分是**红脸离岗**：不产张数，但从离岗那一刻起按 `v` 恢复（总规范 §4.2）。不存在“留在岗位上干等”的时段。

## 6. 边界

- **单班模式**（只放一组人，红脸后回满再战）：`周期 = 1/d + 回满`，`张数/日 = E·(1/d)·24 / (周期 × 24.4444)`，见排班文档 §5.2。
- 只算在岗期间的收集量；离岗休息与中枢加成只在「可回复」一项里出现。
- 不换算成情报档案（数据里该项恒为 0）。

## 7. 候选干员池

`roomType=5`（会客室线索区）在全干员里有技能者共 **15 人**（完整名单见 `documents\帝江号设施与干员.md`），其中能提升张数的只有下面 6 人：

| 干员 | 收集加成 | 减免 | 另一槽 |
|---|---|---|---|
| 艾尔黛拉 | 30% | 18% | 会客室（同舱双槽） |
| 洛茜 | 30% | 18% | 会客室（同舱双槽） |
| 祀 | 30% | 18% | 会客室（同舱双槽） |
| 埃特拉 | 30% | — | 中枢·全体心情恢复 |
| 梨诺 | — | 18% | 中枢·全体心情恢复 |
| 秋栗 | — | 18% | 制造舱·心情消耗降低 |

- 同时具备收集与减免的只有前三名 ⇒ **A 组上限（加成 90%、减免 54%）唯一由这三人达成**，不可替代。
- 会客室 6 人次（3 工位 × 2 班）；B 班用不上减免，只需 1 名收集 + 2 占位。

## 8. 可选：助力（默认关闭）

> 本节是**开关**：默认 `a = 0`，前面的算法、示例、结论一字不变。只有要算“每天用几次中枢助力才能把会客室效率推高”时才启用。

### 8.1 机制

| 项 | 口径 |
|---|---|
| 来源 | 好友对**总控中枢**助力（会客室自己不吃助力，`helpDesc` 为空） |
| 次数 | **2 点/天**（`centerBeHelpedCountLimit = 2`），04:00 刷新，当天不用作废 |
| 换算 | 1 点 = **给一名干员 +3000 心情 = +30%**（`centerBeHelpedRewardPhysicalStrength = 3000` ÷ 上限 10000） |
| 对象 | **任意**在岗/离岗干员；但两点必须给**两名不同**干员 |
| 上限 | 目标心情 ≥100% 时**不可选** ⇒ 只能在心情 ≤70% 时用，否则溢出作废 |
| 分配顺序 | 会客室 → 干员经验制造 → 武器经验制造 → 培养舱（见排班文档 §6.3 第 5 条） |

**每次助力能多干多久**：`+30% ÷ d`。会客室 A 班 `d = 3.312%` ⇒ **9.06 h**。

### 8.2 阈值：要 **2 次**，1 次不够

A 组三人共用同一个 `d`、同一个休息窗，缺口完全一样，所以要算的是「每人每天能补多少」：

```text
h = 21 时：C = 21 × 3.312% = 69.552%      R = 3 h × 17.76% = 53.28%
每人每天缺口 = 69.552% − 53.28% = 16.272%
```

- **1 点**：只救得起 1 人（+30%/天 > 缺口），另外两人仍按 16.272%/天同步衰减、同一天一起红脸 ⇒ 从那天起班末只剩 1 人在岗（倍率 1.82）。逐日模拟的**长期均值 94.38**，比 20/4 的 95.04 还低。（首日 ~96.36 是满心情的假象，不能当依据。）
- **2 点**：3 天一轮、每人每 3 天吃 2 次 = `60% ÷ 3 天 = 20%/天` > 缺口 16.272% ⇒ **三人全部撑住**，天天满 21 h，日产稳定在 96.36。

| `a` | 最优方案 | 日产出 | 相对 20/4 |
|---|---|---|---|
| 0 | 20/4 稳定 | 95.04 | — |
| 1 | 20/4 稳定，点数顺延出去（本舱心情本来就回满，加了也溢出） | 95.04 | ±0 |
| **2** | **21/3 + 三天轮转** | **96.36** | **+1.32** |

```text
阈值 a* = min{ a : 日产出(a) > 95.04 } = 2
```

> **1 点单独给会客室是没有收益的**——这是分配规则必须“按整组评估”的原因（排班文档 §6.3）。也因为 2 点的边际收益为正，两点都留在会客室，不会顺延出去。

### 8.3 为什么不能更长

`h = 22` 时缺口涨到 `72.864% − 35.52% = 37.34%/天`，而轮转最多只能给每人 20%/天 ⇒ 撑不住。

按同一套逐日模拟（21/3 与 22/2 都用 3 天轮转、注入时刻取“心情降到 70%”那一刻）：

| 班长 | B 班 | 缺口/天 | 轮转能补 | 长期日产出 |
|---|---|---|---|---|
| 21/3 | 3 h | 16.272% | 20% | **96.36** |
| 22/2 | 2 h | 37.344% | 20% | 92.30 |

### 8.4 三天轮转表（每 3 天重复）

| 天 | 点数发给 | 开工心情（三人） | 注入时刻（心情降到 70%） | 日产 |
|---|---|---|---|---|
| 1 | ①② | 83.7% / 97.5% / 100.0% | 4.14 h / 8.29 h / — | 96.36 |
| 2 | ①③ | 97.5% / 100.0% / 83.7% | 8.29 h / — / 4.14 h | 96.36 |
| 3 | ②③ | 100.0% / 83.7% / 97.5% | — / 4.14 h / 8.29 h | 96.36 |

- 每人每 3 天正好吃 2 次，稳态下**没有一天红脸**，三人天天满 21 h。
- 心情进入 3 天循环（只在 83.7% / 97.5% / 100% 三个值之间轮转），不再需要逐日模拟。
- **注入时刻只要目标心情 ≤70% 即可，早用晚用等价**：+30% 是定量，不是按时间恢复，早晚注入对当天的可用总量没有区别。

**使用区间**（A 班 0:00–21:00）：

```text
A 班开工后「目标干员心情降到 70%」起，到 21:00 下班前
稳态：最早 04:08（开工 83.7% 的人）、最晚 08:17（开工 97.5% 的人）
首日三人皆满，最晚可到 09:03
⇒ 每天 04:08 之后、21:00 之前，把 2 点发给当轮指定的那 2 人
```

> 04:00 刷新、当天用掉；这个窗口整个落在同一个 04:00–次日 04:00 的计费日里，不会跨刷新点被清空。

### 8.5 收益

| 项 | 无助力 | 2 次助力 | 差 |
|---|---|---|---|
| 等效小时/日 | 95.04 | **96.36** | +1.32 |
| 张数/日 | 3.8880 | **3.9420** | +0.0540 |
| 信用/日 | 77.76 | **78.84** | +1.08 |

- 折到每次助力：`1.08 ÷ 2 = 0.54 信用/次`。
- 增益来自“把 20/4 的稳定班换成 21/3”，不是来自“给已经稳定的班加点”——20/4 本来就天天回满，加点全部溢出作废，收益为 0。
