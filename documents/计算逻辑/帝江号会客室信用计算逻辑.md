# 帝江号会客室信用计算逻辑

> 只算一条产出线：会客室在岗干员自行收集的线索 × 20 信用。只涉及在岗的干员；离岗休息、中枢加成、心情闭环的分段算法见 `documents/计算逻辑/帝江号排班与产出计算逻辑.md`。

## 1. 变量

| 变量 | 旧符号 | 含义 |
|---|---|---|
| 收集加成 | `ΣC1` | 在岗者线索收集效率之和（30% / 20%） |
| 减免 | `ΣB2` | 在岗者心情消耗降低之和（18% / 14%） |
| 在岗人数 | `N` | Lv3 工位 3，`N ≤ 3` |
| 倍率 | `E` | 该班组的实际收集倍率 |
| 心情消耗 | `d` | 每人每小时心情消耗 |
| 班长 | `h` | 该班在岗小时数（整数，A 班从 00:00 起） |
| 有效时长 | `H` | 真正在生产的时长 |
| 等效小时 | `Y` | 该班产出量（以 100% 速度的小时计） |
| 张数 | — | 该班收集到的线索张数 |
| 信用 | — | 张数 × 20 |

| 常数 | 值 |
|---|---|
| 基础耗时 | 25.63 h / 张（无加成时的单张耗时） |
| 单张信用 | 20 |
| 人数项系数 | 每人 +40% ⇒ 3 人满编 `1 + 0.40 × 3 = 2.2` |
| 基础心情消耗 | 0.072 / 小时 |

## 2. 算式

```text
加成      = Σ 线索收集效率
减免      = Σ 心情消耗降低
倍率      = (1 + 0.40 × 在岗人数) × (1 + 加成)
心情消耗  = 0.072 × (1 − 减免)
有效时长  = min(班长, 1 / 心情消耗)               # 超出部分是停产等待，不计产出
本班消耗  = min(1, 心情消耗 × 班长)
可回复    = Σ 回复速度 × 休息时长
可行      = 可回复 ≥ 本班消耗

单张耗时  = 25.63 / 倍率
等效小时  = 倍率 × 有效时长
张数      = 等效小时 / 25.63
信用      = 20 × 张数
```

**注意**：线索概率技能只决定线索倾向，不进倍率；只有「线索收集效率」与「心情消耗降低」进公式。

## 3. 示例

A 组 = 洛茜 + 艾尔黛拉 + 祀（三人均 30% 收集 + 18% 减免，双槽同会客）；B 组 = 埃特拉（30%）+ 秋栗（18% 减免）+ 占位。

| | A 班（20 h） | B 班（4 h） |
|---|---|---|
| 加成 / 减免 | 90% / 54% | 30% / 18% |
| 倍率 | `2.2 × 1.90 = 4.18` | `2.2 × 1.30 = 2.86` |
| 心情消耗 | 3.312% | 5.904% |
| 有效时长上限 `1/心情消耗` | 30.193 h | 16.938 h |
| 有效时长 | 20（未及上限） | 4 |
| 单张耗时 | `25.63 / 4.18 = 6.1316 h` | `25.63 / 2.86 = 8.9615 h` |
| 等效小时 | 83.60 | 11.44 |
| 张数 | 3.2618 | 0.4464 |
| 信用 | 65.24 | 8.93 |

```text
张数/日 = 3.7082      等效小时 = 95.04      信用/日 = 74.16
```

## 4. 减免的价值门槛

`有效时长 = min(班长, 1/心情消耗)` ⇒ **减免只在班长超过 `1/心情消耗` 时才产生价值**：

```text
需要的减免 = 1 − 1/(0.072 × 班长)
```

A 班 20 h 的门槛是 **30.56%**：

| 减免 | 心情消耗 | 有效时长上限 | 张数 |
|---|---|---|---|
| 0% | 7.200% | 13.889 h | 2.2651 |
| 18% | 5.904% | 16.938 h | 2.7624 |
| **36%** | 4.608% | 21.701 h | **3.2618**（撑满 20 h） |
| 54% | 3.312% | 30.193 h | 3.2618（与 36% 同值） |

**结论**：A 班 20 h 至少要 2 人各 18% 才不吃亏；**B 班只有 4 h，任何减免都不会归零，减免在 B 班价值为 0**。

## 5. 缺人与停产

- 在岗人数取实际值：`N=2` → 人数项 1.8（产出 −18.2%），`N=1` → 1.4（−36.4%）。**只有缺的是不贡献技能的占位干员时**才只有这一项损失；若缺的是收集或减免干员，加成/减免也会跟着掉，损失远大于 18.2%。
- `班长 > 1/心情消耗` 的超出部分是停产等待：不计张数、不回心情，但仍占着班长。

## 6. 边界

- 只算在岗期间的收集量；离岗休息与中枢加成只在「可回复」一项里出现。
- 不换算成情报档案（数据里该项恒为 0）。
- 不做排班推荐、不做全船联解、不做线索概率的定量收益。

## 7. 候选干员池

`roomType=5` 有技能者 15 人，其中能提升张数的只有 6 人：

| 干员 | 收集加成 | 减免 | 备注 |
|---|---|---|---|
| 艾尔黛拉 | 30% | 18% | 双槽同会客 |
| 洛茜 | 30% | 18% | 双槽同会客 |
| 祀 | 30% | 18% | 双槽同会客 |
| 埃特拉 | 30% | — | 另一槽为中枢 |
| 梨诺 | — | 18% | 另一槽为中枢（通常被中枢占用） |
| 秋栗 | — | 18% | 另一槽为制造舱 |

- 同时具备收集与减免的只有前三名 ⇒ **A 组的上限（加成 90%、减免 54%）唯一由这三人达成**。
- 会客室 6 人次（3 工位 × 2 班）；B 班用不上减免，故只需 1 名收集 + 2 占位。
