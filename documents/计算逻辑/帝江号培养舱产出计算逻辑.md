# 帝江号培养舱产出计算逻辑

> 本文算**单舱、单班次**的产出。培养舱有 9 个培养位、3 个工位，**两者**是两回事：工位决定“几个人在岗”，槽位决定“同时种几株”。
> 心情闭环的通用口径（`R ≥ C`、中枢 `u(t)` 分段、红脸与返岗）见 `帝江号排班与产出计算逻辑.md` §4。

## 0. 术语

| 术语 | 含义 |
|---|---|
| 培养位（槽） | 9 个种植格。按等级解锁：Lv1 → 1–3、Lv2 → 4–6、Lv3 → 7–9 |
| 工位 | 可进驻的干员数：Lv1/2/3 → 1/2/3 人。**人数项看工位，不看槽位** |
| 批次 | 一个槽从开种到收获的一次完整周期。金色 R5 一批的基线是 **125 h** |
| 单槽产出 | 一个槽在一个班次里推进的量（等效小时） |
| 最终生长时间 | 该班倍率下一批的真实耗时 = `125 / 倍率` |
| **单槽**收割次数 | 一个槽在一个班次内能收几次（**连续值**，可跨班累加；恒小于 1） |
| **舱级**收割次数 | `槽数 × 单槽收割次数`。跨类别比较、汇总到全船时用这个 |

## 1. 变量与前提

| 变量 | 含义 |
|---|---|
| 槽数 | 9 个培养位里该类的数量，三类之和 = 可用培养位数 |
| 在岗人数 | Lv3 = 3 |
| 加成 | 在岗者中作用于**该类别**的培养速度加成之和 |
| 减免 | 在岗者中心情消耗降低之和 |
| 倍率 | 该类槽位的实际培养倍率（舱级） |
| 心情消耗 | 每人每小时心情消耗 |
| 班长 | 该班在岗小时数（整数） |
| 有效时长 | 真正在生产的时长 |
| 本班消耗 / 可回复 | 本班用掉的心情 / 休息期能回的心情 |
| 权重 | 玩家偏好，默认 晶3 / 菌2 / 矿1；综合分 = Σ 权重 × 舱级收割次数，§3 示例就用这个默认值 |

**三条前提**

1. **培养位同质**：9 个槽只有解锁批次不同，没有逐槽参数，方案只由「各类各占几个」决定。
2. **加成按类别隔离**：菌类 / 晶植 / 矿物是三条独立属性，晶植的 30% 对菌类槽毫无贡献。
3. **人数项是舱级的**：Lv3 = 2.2，对 9 个槽全部适用；没被加成的类别也是 2.2，不是 1。

| 等级 | 工位 | 培养位 | 人数项 | 单类加成上限 | 单类倍率上限 |
|---|---|---|---|---|---|
| Lv1 | 1 | 3 | 1.4 | 30% | 1.82 |
| Lv2 | 2 | 6 | 1.8 | 60% | 2.88 |
| Lv3 | 3 | 9 | **2.2** | **90%** | **4.18** |

## 2. 算式

```text
b         = Σ 作用于该类的培养速度加成
r         = Σ 心情消耗降低
E         = (1 + 0.40 × N) × (1 + b)                # 倍率（舱级）
d         = 0.072 × (1 − r)
H         = min(h, 起点心情 / d)                     # 满心情时 = min(h, 1/d)
C         = min(1, d × h)
R         = Σ v_k × Δt_k                            # 按中枢 u(t) 分段
稳定      = R ≥ C
不稳定    = 长期值 E_A·min(h, W*) + E_B·(24−h)       # 总规范 §4.4；撞顶要逐日模拟

最终生长时间   = 125 / E
单槽收割次数   = H / 最终生长时间                    # 恒小于 1
舱级收割次数   = 槽数 × (A 班单槽 + B 班单槽)
件数           = 舱级收割次数 × 每批件数              # 晶植 3 件/批，菌与矿 1 件/批
单槽等效小时   = E × H                              # 一个槽推进的量
综合分         = Σ 权重 × 舱级收割次数                # 跨类别比较用，见 §3
单班模式       = 周期 = 1/d + t满；单槽等效小时/日 = E·(1/d)·24/周期
```

**四个要点**

- **加成按类别隔离**：每一类单独算倍率与生长时间；两班倍率不同就分别算，不能取平均。
- **单槽与舱级必须分清**：`H / 125/E` 算出来的是**单槽**；`单槽 × 槽数` 才是**舱级**。制造舱、会客室的产量本身就是舱级，只有舱级才能和它们并列。
- **综合分与件数是两个口径**：综合分按“批”算（不含每批件数），件数按“物品”算（含 ×3）。晶植每批 3 件、权重也是 3，两者**恰好相等**；一旦涉及菌（权重 2 但每批 1 件），两者就会分叉——见 §3 末。
- **单槽收割次数恒小于 1**：满配一批也要 `125/4.18 = 29.9 h`，所以「日收割」是进度量，实际收获跨班次、跨天。
- **红脸是离岗**：`h > 1/d` 的部分不计产出，但从那一刻起人离岗并按 `v` 恢复（总规范 §4.2），不是“原地空转”。

## 3. 示例：6 槽晶植 + 3 槽矿物

舱室 Lv3，A 班 17 h / B 班 7 h；中枢 **h = 14**：A 段 0–14（12%，`v = 13.44%`）、B 段 14–24（48%，`v = 17.76%`）。B 班的休息窗 [0,17] 跨两段，`R = 14×13.44% + 3×17.76% = 2.4144`。

| | A 班 | B 班 |
|---|---|---|
| 名单 | 诀（晶 30 + 矿 30）+ 别礼（晶 30）+ 汤汤（晶 30、心情 18） | 陈千语（矿 30）+ 狼卫（矿 30）+ 卡契尔（心情 18） |
| 加成 菌/晶/矿 | 0 / **90%** / **30%** | 0 / 0 / **60%** |
| 减免 | 18% | 18% |
| 倍率 菌/晶/矿 | 2.20 / **4.18** / **2.86** | 2.20 / 2.20 / **3.52** |
| 心情消耗 | 5.904% | 5.904% |
| 有效时长 | 16.937669 | 7 |
| 本班消耗 C / 可回复 R | 1.000000 / 1.2432 ✔ | 0.413280 / 2.4144 ✔ |
| 最终生长时间 | 晶 29.90 h，矿 43.71 h | 晶 56.82 h，矿 35.51 h |
| 收割次数 / 槽 | 晶 0.566396，矿 0.387534 | 晶 0.123200，矿 0.197120 |

```text
# 最终生长时间 = 125 / 倍率
A 班：晶 125/4.18 = 29.904 h    矿 125/2.86 = 43.706 h
B 班：晶 125/2.20 = 56.818 h    矿 125/3.52 = 35.511 h

# 收割次数（单槽）= 有效时长 / 最终生长时间
A 班：晶 16.937669/29.904 = 0.566396    矿 16.937669/43.706 = 0.387534
B 班：晶 7/56.818 = 0.123200            矿 7/35.511 = 0.197120

# 舱级 = 槽数 ×（A 班 + B 班）
晶：6 × (0.566396 + 0.123200) = 6 × 0.689596 = 4.137574 次/日 → 件数 12.412722
矿：3 × (0.387534 + 0.197120) = 3 × 0.584654 = 1.753962 次/日 → 件数 1.753962

日收割 = 5.891536      日件数 = 14.166684
综合分（默认权重 晶3/菌2/矿1）= 3 × 4.137574 + 1 × 1.753962 = 14.166684

# 本示例里两者恰好相等：晶的权重 3 正好等于每批 3 件、矿的权重 1 等于每批 1 件
# 换一类就分叉：菌的权重是 2、但每批只有 1 件 ⇒ 菌的综合分是件数的 2 倍
```

> **这就是「两个口径」的真实含义**：**综合分**是玩家偏好加权后的可比量，**件数**是实际到手物品数。本示例因为晶/矿的权重恰好等于件/批比值，两个数才撞在一起——**不能因此认为它们永远相等**。

> **诀**一人在 A 班同时给晶 30% + 矿 30%，所以「晶 + 矿」混合几乎零成本；池子里没有「晶 + 菌」的桥接干员，混这两类必掉一档加成。
> **注意量纲**：上表「单槽收割次数」是单槽值，乘槽数才是舱级；而制造舱、会客室的产量本身就是舱级，两者不能直接并列。

## 4. 减免的价值门槛

有效时长 = `min(班长, 1/心情消耗)` ⇒ 减免只在班长超过 `1/心情消耗` 时才有价值：

```text
需要的减免 = 1 − 1/(0.072 × 班长)      # 班长 ≤ 13 时恒为 0
```

| 班长 | 需要的减免 | 最低够用档位 | 心情消耗 | 有效时长上限 |
|---|---|---|---|---|
| ≤ 13 | 0 | 0% | 7.200% | 13.888889 h |
| 14 | 0.79% | 18% | 5.904% | 16.937669 h |
| 16 | 13.19% | 18% | 5.904% | 16.937669 h |
| **17** | **18.30%** | **36%** | 4.608% | 21.701389 h |
| 18 | 22.84% | 36% | 4.608% | 21.701389 h |
| 20 | 30.56% | 36% | 4.608% | 21.701389 h |
| 22 | 36.87% | 54% | 3.312% | 30.193237 h |
| 24 | 42.13% | 54% | 3.312% | 30.193237 h |

> 培养舱的心情技能只有 18% 一档，可用档位是 `{0, 18, 36, 54}`（最多 3 人：伊冯、汤汤、卡契尔/安塔尔）。

**读法**：班长 17 h 需要 18.30%，单个 18% 差 0.30 个百分点，损失只有 3 分 44 秒；为此换掉一个 +30% 加成干员（4.18 → 2.86，−31.6%）是净亏。

## 5. 缺人与停产

| 场景 | 人数项 | 加成 | 倍率 | 相对满编 |
|---|---|---|---|---|
| 满编（别礼/汤汤/诀） | 2.2 | 90% | 4.18 | 100.0% |
| 换入 1 名纯心情干员（2 加成 + 1 心情） | 2.2 | 60% | 3.52 | **84.2%** |
| 缺 1 人、**无人被单独补心情**（合并口径） | — | ≤ 60% | **0**（整舱停产） | 见下 |
| 缺 1 人、**有人被助力补过心情**（分人口径） | 1.8 | ≤ 60% | ≤ 2.88 | **≤ 68.9%**（人数项 81.8% × 加成项 84.2%） |

90% 必须由三个 30% 加成位凑满，所以不存在「带着纯心情干员还有 90%」的班组。

**“少 1 人”有两种结果**（总规范 §4.6）：默认合并口径下同班心情同步 ⇒ **三人同时红脸** ⇒ 整舱停产、产出 0；只有被助力打破同步后才会出现“2 人在岗”，这时倍率才按 2.88 算。

**红脸离岗**：`h > 1/d` 的部分不计产出，但从红脸那一刻起人离岗并按 `v` 恢复（总规范 §4.2）。例：`r = 18%` 时 `1/d = 16.94 h`，班长排 17 h，则最后 3 分 44 秒离岗休息——`H = 16.94 > 16`，所以仍比排 16 h 划算。

## 6. 边界

- **单班模式**（只放一组人，红脸后回满再战）：`周期 = 1/d + t满`，单槽等效小时/日 `= E·(1/d)·24/周期`（`E`/`d`/`t满` 见 §2）。周期不整除 24，只保证长期平均（总规范 §5.2）。
- 不计种子/基核闭环：提取是 `1 质料 → 3 基核`、每批耗 `1 基核` ≈ `1/3` 质料，若计入则净件数折扣为晶植 ×0.889、菌/矿 ×0.667。
- 不承诺整批完成，不建模库存上限与收获相位。
- 一律取技能最高档（γ，无 γ 则 β）。

## 8. 可选：助力（默认关闭）

> 培养舱**自己**的助力（+1 基核）不在本模型内。这里只算一种情况：中枢那 2 点心情点数**顺延**到本舱。

- 1 点 = 单干员 +30% 心情 ⇒ 多干 `30% ÷ 5.904% = 5.08 h`（18% 减免档）。
- **前提是本舱正在衰减**。本舱若已稳定（心情每天回满 100%），加点全部溢出作废，收益恒为 0。
- 顺延到本舱时，被补的那一班心情转**分人**（先红脸者先离岗，倍率按实际在岗人数重算），见 `帝江号排班与产出计算逻辑.md` §4.6。
- 示例方案（培养 17 h / 7 h、中枢 48%）：`R = 7 × 17.76% = 124.32% ≥ C = min(1, 17 × 5.904%) = 100%`，**已经稳定** ⇒ 顺延到本舱的收益为 0。
- 真正吃得到助力的是**矿物类**：矿 30% 的四人全无减免 ⇒ `d = 7.2%`、`1/d = 13.889 h`，班长一超过 13.889 h 就必然红脸。
