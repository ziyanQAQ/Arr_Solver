# 帝江号培养舱产出计算逻辑

> 给定「9 个培养位里各类占几个 + 在岗 3 人 + 班长」，算出一个班次能收几次、多少件。
> 心情闭环的通用口径见 `帝江号排班与产出计算逻辑.md` §4。

## 1. 变量

| 变量 | 含义 |
|---|---|
| 槽数 | 9 个培养位里该类的数量，三类之和 = 可用培养位数 |
| 在岗人数 | Lv3 = 3 |
| 加成 | 在岗者中作用于**该类别**的培养速度加成之和 |
| 减免 | 在岗者中心情消耗降低之和 |
| 倍率 | 该类槽位的实际培养倍率 |
| 心情消耗 | 每人每小时心情消耗 |
| 班长 | 该班在岗小时数（整数） |
| 有效时长 | 真正在生产的时长 |
| 本班消耗 / 可回复 | 本班用掉的心情 / 休息期能回的心情 |
| 最终生长时间 | 该班倍率下一批的真实耗时 = `125 / 倍率` |
| 收割次数 | 一个班次内该槽位能收几次 |
| 权重 | 玩家偏好，默认按优先级 3/2/1 |

**三条前提**

1. **培养位同质**：9 个槽只有解锁批次（1–3 / 4–6 / 7–9）不同，没有逐槽参数，方案只由槽数决定。
2. **加成按类别隔离**：菌类 / 晶植 / 矿物三条独立属性，晶植的 30% 对菌类槽毫无贡献。
3. **人数项是舱级的**：Lv3 = 2.2，对 9 个槽全部适用；没被加成的类别也是 2.2，不是 1。

| 等级 | 工位 | 培养位 | 人数项 | 单类加成上限 | 单类倍率上限 |
|---|---|---|---|---|---|
| Lv1 | 1 | 3 | 1.4 | 30% | 1.82 |
| Lv2 | 2 | 6 | 1.8 | 60% | 2.88 |
| Lv3 | 3 | 9 | **2.2** | **90%** | **4.18** |

## 2. 算式

```text
加成      = Σ 作用于该类的培养速度加成
减免      = Σ 心情消耗降低
倍率      = (1 + 0.40 × 在岗人数) × (1 + 加成)
心情消耗  = 0.072 × (1 − 减免)
有效时长  = min(班长, 1 / 心情消耗)
本班消耗  = min(1, 心情消耗 × 班长)
可回复    = Σ 回复速度 × 休息时长
可行      = 可回复 ≥ 本班消耗

单班产出     = 倍率 × 有效时长
最终生长时间 = 125 / 倍率
收割次数     = 槽数 × 有效时长 / 最终生长时间
件数         = 收割次数 × 每批件数
综合分       = Σ 权重 × 收割次数
日收割次数   = A 班 + B 班
```

**三个要点**

- **加成按类别隔离**：每一类单独算倍率与生长时间；两班倍率不同就分别算，不能取平均。
- **综合分用批次口径**（不含件数），**件数用物品口径**（晶植每批 3 件、菌/矿 1 件）。两者会分叉。
- **单槽收割次数恒小于 1**：满配一批也要 `125/4.18 = 29.9 h`，所以「日收割」是进度量，实际收获跨班次、跨天。

## 3. 示例：6 槽晶植 + 3 槽矿物

舱室 Lv3，A 班 17 h / B 班 7 h。

| | A 班 | B 班 |
|---|---|---|
| 名单 | 诀（晶 30 + 矿 30）+ 别礼（晶 30）+ 汤汤（晶 30、心情 18） | 陈千语（矿 30）+ 狼卫（矿 30）+ 卡契尔（心情 18） |
| 加成 菌/晶/矿 | 0 / **90%** / **30%** | 0 / 0 / **60%** |
| 减免 | 18% | 18% |
| 倍率 菌/晶/矿 | 2.20 / **4.18** / **2.86** | 2.20 / 2.20 / **3.52** |
| 心情消耗 | 5.904% | 5.904% |
| 有效时长 | 16.937669 | 7 |
| 本班消耗 / 可回复 | 1.000000 / 1.2432 ✔ | 0.413280 / 1.1760 ✔ |
| 单班产出 | 晶 70.79946，矿 48.44173 | 晶 15.40，矿 24.64 |
| 最终生长时间 | 晶 29.90 h，矿 43.71 h | 晶 56.82 h，矿 35.51 h |
| 收割次数 / 槽 | 晶 0.566396，矿 0.387534 | 晶 0.123200，矿 0.197120 |

```text
晶：6 × (0.566396 + 0.123200) = 6 × 0.689596 = 4.137574 次/日 → 件数 12.412722
矿：3 × (0.387534 + 0.197120) = 3 × 0.584654 = 1.753962 次/日 → 件数 1.753962
日收割 = 5.891536      日件数 = 14.166684
综合分（权重 菌2/晶3/矿1）= 3 × 4.137574 + 1 × 1.753962 = 14.166684
```

> 诀一人在 A 班同时给晶 30% + 矿 30%，所以「晶 + 矿」混合几乎零成本；池子里没有「晶 + 菌」的桥接干员，混这两类必掉一档加成。

## 4. 减免的价值门槛

`有效时长 = min(班长, 1/心情消耗)` ⇒ 减免只在班长超过 `1/心情消耗` 时才有价值：

```text
需要的减免 = 1 − 1/(0.072 × 班长)      # 班长 ≤ 13 时恒为 0
```

| 班长 | 需要的减免 | 最低够用档位 | 心情消耗 | 有效时长上限 |
|---|---|---|---|---|
| ≤ 13 | 0 | 0% | 7.200% | 13.888889 h |
| 14 | 0.79% | 18% | 5.904% | 16.937669 h |
| 16 | 13.19% | 18% | 5.904% | 16.937669 h |
| **17** | **18.30%** | **36%** | 4.608% | 21.701389 h |
| 18 | 22.84% | 36% | 4.608% | 21.701389 h |
| 20 | 30.56% | 36% | 4.608% | 21.701389 h |
| 22 | 36.87% | 54% | 3.312% | 30.193237 h |
| 24 | 42.13% | 54% | 3.312% | 30.193237 h |

> 培养舱的心情技能只有 18% 一档，可用档位是 `{0, 18, 36, 54}`（最多 3 人：伊冯、汤汤、卡契尔/安塔尔）。

**读法**：班长 17 h 需要 18.30%，单个 18% 差 0.30 个百分点，损失只有 3 分 44 秒；为此换掉一个 +30% 加成干员（4.18 → 2.86，−31.6%）是净亏。

## 5. 缺人与停产

| 场景 | 人数项 | 加成 | 倍率 | 相对满编 |
|---|---|---|---|---|
| 满编（别礼/汤汤/诀） | 2.2 | 90% | 4.18 | 100.0% |
| 换入 1 名纯心情干员（2 加成 + 1 心情） | 2.2 | 60% | 3.52 | **84.2%** |
| 少 1 人（任何原因） | 1.8 | ≤ 60% | ≤ 2.88 | **≤ 68.9%**（人数项 81.8% × 加成项 84.2%） |

90% 必须由三个 30% 加成位凑满，所以不存在「带着纯心情干员还有 90%」的班组。停产等待：`班长 > 1/心情消耗` 的部分不计产出、不回心情。

## 6. 边界

- **单班模式**（只放一组人，红脸后回满再战）：`周期 = 1/d + 回满`，`日产出 = E·(1/d)·24/周期`，见排班文档 §5.2。
- 不计种子/基核闭环：提取是 `1 质料 → 3 基核`、每批耗 `1 基核` ≈ `1/3` 质料，若计入则净件数折扣为晶植 ×0.889、菌/矿 ×0.667。
- 不承诺整批完成，不建模库存上限与收获相位。
- 一律取技能最高档（γ，无 γ 则 β）。
