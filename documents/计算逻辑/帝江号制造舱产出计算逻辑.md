# 帝江号制造舱产出计算逻辑

> 只算产出，不做排班推荐。给定「在产配方 + 在岗干员 + 班长」，算出该班能收几件、多少经验、能否逐日循环。
> 全船制造舱上限 **2 间**，本文按**单舱单班单配方**算（一次只跑一个方案，单产线串行）。

## 1. 变量

| 变量 | 旧符号 | 含义 |
|---|---|---|
| 在岗人数 | `N` | Lv3 = 3 |
| 加成 | `b` | 在岗者中作用于**该 expType** 的生产效率之和 |
| 减免 | `r` | 在岗者中心情消耗降低之和 |
| 倍率 | `E` | 该班组的实际生产倍率 |
| 心情消耗 | `d` | 每人每小时心情消耗 |
| 班长 | `h` | 该班在岗小时数（整数） |
| 有效时长 | `H` | 真正在生产的时长 |
| 本班消耗 | `C` | 该班用掉的心情 |
| 可回复 | `R` | 休息期内能回复的心情 |
| 单件基线 | — | 100% 速度、无加成时生产 1 件的耗时 = `进度 / 360,000` |
| 收割次数 | — | 一个班次内能收几件（连续值） |
| 权重 | `w` | 玩家偏好，默认干员经验 : 武器经验 = 1 : 1 |

**四条前提**

1. **一个舱一次只能产一种类型**：单产线串行，只能跑一个配方；而配方分两类（干员经验 / 武器经验），所以**同一间舱的产出永远是单一类别**，不存在“一舱同时出两种”。要同时产两类，只能用第二间舱。
2. **加成按 expType 隔离**：制造舱有两条独立效率属性（`roomAttrType=16` 干员培养素材、`=17` 武器培养素材），配方按自己的类型取一条。生产干员经验时吃不到武器经验加成，反之亦然。
3. **人数项是舱级的**：Lv3 = `1 + 0.40 × 3 = 2.2`，另一类没有被加成时也是 2.2，不是 1。
4. **生产载荷不影响速度**：`machineCapacity` 只限制单次最多排几件（`floor(载荷 / 每件占用)`），单件耗时与总耗时公式里都没有它。

| 等级 | 进驻人数上限 | 生产载荷 | 人数项 |
|---|---|---|---|
| Lv1 | 1 | 120 | 1.4 |
| Lv2 | 2 | 240 | 1.8 |
| Lv3 | 3 | 480 | **2.2** |

## 2. 算式

```text
加成      = Σ 该 expType 的生产效率提升            # 干员经验 / 武器经验各自汇总
减免      = Σ 心情消耗降低
倍率      = (1 + 0.40 × 在岗人数) × (1 + 加成)
心情消耗  = 0.072 × (1 − 减免)
有效时长  = min(班长, 1 / 心情消耗)               # 超出部分是停产等待，不计产出
本班消耗  = min(1, 心情消耗 × 班长)
可回复    = Σ 回复速度 × 休息时长                  # 回复速度 = 0.12 × (1 + 中枢加成)
可行      = 可回复 ≥ 本班消耗

单件耗时  = 单件基线 / 倍率
收割次数  = 有效时长 / 单件耗时                    # 连续值，可跨班累加
完成件数  = floor(日收割次数)                      # 整批取整
日经验    = 10,000 × 日收割次数                    # 两类每件都是 10,000 经验
综合分    = Σ 权重 × 日收割次数                    # 仅在两舱各跑一类时合并用，默认 1:1
```

**五个必须注意的点**

- **一个舱只会有一类产出**：所以“收割次数 / 完成件数 / 日经验”都是单一类别的量，不存在舱内相加。
- **同一班组换配方，倍率会变**：干员向的班组生产武器经验时，`加成 = 0`，倍率只剩 2.2。
- **取整要放在日合计之后**：`floor(A 班 + B 班)`，而不是两班各自取整再相加，否则半件进度会凭空消失。
- **两类单件基线差 2.5 倍**：高级认知载体 24h26m40s、武器检查套组 9h46m40s（同为 10,000 经验/件）。这是“按稀有度最高”取 R5 的直接代价。
- **权重只在跨舱时才登场**：两类每件都恰好 10,000 经验，数量单位相同，所以 1:1 是事实而非偏好；但既然一舱只产一类，它只用于“两舱各跑一类后合并”或“该跑哪类更划算”的比较。

## 3. 示例：同一舱的两个候选方案（二选一）

舱室 Lv3，A 班 17 h / B 班 7 h。A 班是干员向、B 班是武器向。下表把两种配方都算一遍，用来比较“这间舱该跑哪一类”——**实际只能选一个**，因为一个舱一次只产一种类型。

| | A 班（干员向） | B 班（武器向） |
|---|---|---|
| 名单 | 莱万汀（干员 30、心情 18）+ 庄方宜（心情 18、干员 30）+ 余烬（干员 30） | 洁尔佩塔（武器 30、心情 18）+ 骏卫（武器 30、心情 18）+ 佩丽卡（武器 30） |
| 加成 干/武 | **90%** / 0 | 0 / **90%** |
| 减免 | 36% | 36% |
| 倍率 干/武 | **4.18** / 2.20 | 2.20 / **4.18** |
| 心情消耗 | 4.608% | 4.608% |
| 有效时长 | 17 | 7 |
| 本班消耗 / 可回复 | 0.78336 / 1.2432 ✔ | 0.32256 / 1.1760 ✔ |
| 单件耗时 高级认知载体 | `24.4444 / 4.18 = 5.8480 h` | `24.4444 / 2.20 = 11.1111 h` |
| 单件耗时 武器检查套组 | `9.7778 / 2.20 = 4.4444 h` | `9.7778 / 4.18 = 2.3392 h` |
| 收割次数 高级认知载体 | 2.9070 | 0.6300 |
| 收割次数 武器检查套组 | 3.8250 | 2.9925 |

```text
方案甲（整日只跑干员经验 · 高级认知载体）
  日收割 = 2.9070 + 0.6300 = 3.5370 件  → 完成 3 件 → 日经验 35,370（取整 3 万）

方案乙（整日只跑武器经验 · 武器检查套组）
  日收割 = 3.8250 + 2.9925 = 6.8175 件  → 完成 6 件 → 日经验 68,175（取整 6 万）

两者互斥，只能选一个。若第二间舱跑另一类：
  两舱合计 = 3.5370 + 6.8175 = 10.3545 件/日，日经验 103,545
  综合分（权重 1:1）= 10.3545
```

> 两班倍率配置完全对称（各有一个 4.18 和一个 2.20），但武器经验多出 **92.7%**——**唯一原因是单件基线差 2.5 倍**。若把干员经验换成高级作战记录（同为 3.52M），两类就完全对称了。

## 4. 减免的价值门槛

`有效时长 = min(班长, 1/心情消耗)` ⇒ **减免只在班长超过 `1/心情消耗` 时才产生价值**：

```text
需要的减免 = 1 − 1/(0.072 × 班长)      # 班长 ≤ 13 时恒为 0
```

| 班长 | 需要的减免 | 最低够用档位 | 心情消耗 | 有效时长上限 |
|---|---|---|---|---|
| ≤ 13 | 0 | 0% | 7.200% | 13.888889 h |
| 14 | 0.79% | 14%（昼雪/秋栗） | 6.192% | 16.149871 h |
| 16 | 13.19% | 14% | 6.192% | 16.149871 h |
| 17 | 18.30% | 28%（14+14） | 5.184% | 19.290123 h |
| 18 | 22.84% | 28%（14+14） | 5.184% | 19.290123 h |
| 19 | 26.90% | 28%（14+14） | 5.184% | 19.290123 h |
| 20 | 30.56% | 32%（18+14） | 4.896% | 20.424837 h |
| 21 | 33.86% | 36%（18+18） | 4.608% | 21.701389 h |
| 22 | 36.87% | **46%（18+14+14）** | 3.888% | 25.720164 h |
| 23 | 39.61% | **46%（18+14+14）** | 3.888% | 25.720164 h |
| 24 | 42.13% | **46%（18+14+14）** | 3.888% | 25.720164 h |

> 制造舱的心情技能有 **18% 与 14% 两档**，所以可用档位是 `{14, 18, 28, 32, 36, 46, 50, 54}`（最多 3 人；14% 档只有昼雪、秋栗两人）。

**读法**：班长 17 h 只差 0.30 个百分点，单靠一个 18% 档不够（16.937669 h），损失仅 3 分 44 秒；班长 20 h 需 30.56%，得凑到 32%（18+14）；到 22 h 需要 46%（18+14+14），三个工位就全被心情占满，产线一点加成都不剩。**班长越长，减免越值钱；班长 ≤ 13 h 时减免一分不值。**

## 5. 缺人与停产

| 场景 | 人数项 | 加成 | 倍率 | 相对满编 |
|---|---|---|---|---|
| 满编（三个 30% 加成位） | 2.2 | 90% | 4.18 | 100.0% |
| 换入 1 名纯心情干员（昼雪/秋栗，即 2 加成 + 1 心情） | 2.2 | 60% | 3.52 | **84.2%** |
| 少 1 人（任何原因） | 1.8 | ≤ 60% | ≤ 2.88 | **≤ 68.9%**（人数项 81.8% × 加成项 84.2%） |

**90% 必须由三个 30% 加成位凑满**，所以不存在「带着纯心情干员还有 90% 加成」的班组：换成纯心情干员，加成必然掉到 60%（4.18 → 3.52，−15.8%）；一旦有人离岗，人数项与加成项同时掉（−31.1%）。只有班组本来就是「2 加成 + 1 心情」（倍率 3.52）时，撤掉那名心情干员才只丢人数项：`2.88 / 3.52 = 81.8%`。

停产等待：`班长 > 1/心情消耗` 的部分不计产出、不回心情，但仍占着班长与工位。

## 6. 边界

- 单产线串行，一舱同时只跑一个配方；两舱之间除“抢干员”无耦合，本文不联解。
- 生产载荷只限制单次排产件数（Lv3：高级认知载体 16 件、武器检查套组 40 件），不影响速度。
- 批次内不需要先领取才继续推进；整批跑完会停在「可收取」。
- 切换配方**无材料损耗**，但会丢弃在制进度（无保留）。
- 好友助力：每次 **+2,000,000 进度**，每舱每日最多被助力 2 次（合计 400 万进度 ≈ 0.45 件高级认知载体 / 1.14 件武器检查套组）。不参与主公式。
- 产物存储上限在数据中未定义，不建模。
- 不建模配方切换的排布、不建模多舱共用干员的冲突、不做排班推荐。
- 一律取技能最高档（有 γ 用 γ，否则 β）。
