# 帝江号制造舱产出计算逻辑

> 本文算**单舱、单班次、单配方**的产出。全船制造舱上限 2 间，两舱之间只共享干员、不共享速率，各自算各自的再相加。
> 心情闭环的通用口径（`R ≥ C`、中枢 `u(t)` 分段、红脸与返岗）见 `帝江号排班与产出计算逻辑.md` §4。

## 0. 术语

| 术语 | 含义 |
|---|---|
| 配方 | 在产产物。8 条配方分属干员经验 / 武器经验两类 |
| 单件基线 | 100% 速率下做 1 件要几小时 = `进度上限 / 360,000` |
| 单件耗时 | 该班组倍率下的真实耗时 = `单件基线 / 倍率` |
| 收割次数 | 一个班次内能推进几件（**连续值**，可跨班累加；一天收不完一批也照样计） |
| 完成件数 | 展示用：`floor(日收割次数)`。**经验/进度按未取整的收割算**，见 §2 |
| 班次 | A 班 `00:00–班长`，或 B 班 `班长–24:00` |

## 1. 变量与前提

| 变量 | 符号 | 含义 |
|---|---|---|
| 在岗人数 | `N` | Lv3 = 3（缺人时见 §5） |
| 加成 | `b` | 在岗者中作用于**该 expType** 的生产效率之和 |
| 减免 | `r` | 在岗者中心情消耗降低之和 |
| 倍率 | `E` | `E = (1 + 0.40N)(1 + b)` |
| 心情消耗 | `d` | `d = 0.072 × (1 − r)` |
| 班长 | `h` | 该班在岗小时数（整数 1..23） |
| 有效时长 | `H` | `H = min(h, 起点心情 / d)`，满心情时 = `min(h, 1/d)` |
| 本班消耗 / 可回复 | `C` / `R` | `C = min(1, d·h)`；`R` 按 `u(t)` 分段累加 |
| 单件基线 / 单件耗时 | — | 见「术语」 |

**四条前提**

1. **一个舱一次只能产一种类型**：单产线串行，配方分干员经验 / 武器经验两类，所以同一间舱的产出永远是单一类别；要同时产两类只能用第二间舱。
2. **加成按 expType 隔离**：干员培养素材效能与武器培养素材效能是两条独立属性，产干员经验时吃不到武器经验加成。
3. **人数项是舱级的**：Lv3 = 2.2；另一类没被加成时也是 2.2，不是 1。
4. **生产载荷不影响速度**：`machineCapacity` 只限制单次最多排几件，单件耗时公式里没有它。

| 等级 | 进驻人数上限 | 生产载荷 | 人数项 |
|---|---|---|---|
| Lv1 | 1 | 120 | 1.4 |
| Lv2 | 2 | 240 | 1.8 |
| Lv3 | 3 | 480 | **2.2** |

## 2. 算式

```text
b         = Σ 该 expType 的生产效率提升
r         = Σ 心情消耗降低
E         = (1 + 0.40 × N) × (1 + b)                # 倍率
d         = 0.072 × (1 − r)                         # 心情消耗/小时
H         = min(h, 起点心情 / d)                     # 满心情时 = min(h, 1/d)
C         = min(1, d × h)                           # 本班消耗
R         = Σ v_k × Δt_k                            # 可回复，按中枢 u(t) 分段
稳定      = R ≥ C
不稳定    = 长期值 E_A·min(h, W*) + E_B·(24−h)       # 总规范 §4.4；撞顶要逐日模拟

单件耗时  = 单件基线 / E
收割次数  = H / 单件耗时                             # 连续值，可跨班累加
日收割    = A 班收割 + B 班收割
日经验    = 10,000 × 日收割                          # 按**未取整**的连续值算
完成件数  = floor(日收割)                            # 只用于展示"完成了几个整件"
```

**五个要点**

- **一个舱只有一类产出**：收割次数、完成件数、日经验都是单一类别的量，舱内不相加。
- **同一班组换配方，倍率会变**：干员向的班组产武器经验时 `b = 0`，倍率只剩 2.2（人数项仍是 2.2，不是 1）。
- **取整只影响展示**：进度是连续结算的，`3.5370 件`的进度确实产生了 35,370 经验；`完成 3 件`只是“能兑出 3 个整件”的说法。**不能**把 `floor` 用在经验上，否则每天会凭空损失约 15% 的进度；也不能两班各自取整再相加。
- **两类不能相加**：干员经验件与武器经验件是不同物品，跨类相加违反总规范 §1“只比较同种产物”。
- **两类单件基线差 2.5 倍**：高级认知载体 24.4444 h、武器检查套组 9.7778 h（进度 8.8M vs 3.52M）。

## 3. 示例：跑干员经验 / 跑武器经验，各自的**最优名单**

舱室 Lv3，A 班 17 h / B 班 7 h。中枢 **h = 14**：A 段 0–14（12%，`v = 13.44%`）、B 段 14–24（48%，`v = 17.76%`）。

两类配方各配各的名单——**不能拿一类的最优名单去跑另一类**，那样人数项仍是 2.2，但加成变 0，白亏一倍多。

| | 干员经验 A 班 | 干员经验 B 班 | 武器经验 A 班 | 武器经验 B 班 |
|---|---|---|---|---|
| 名单 | 莱万汀+庄方宜+余烬 | 卡缪+噗切娜+狼卫 | 洁尔佩塔+骏卫+佩丽卡 | 陈千语+弧光+安塔尔 |
| 加成 `b` | **90%** | 80% | **90%** | 60% |
| 减免 `r` | 36% | 0% | 36% | 0% |
| 倍率 `E` | **4.18** | **3.96** | **4.18** | **3.52** |
| 心情消耗 `d` | 4.608% | 7.200% | 4.608% | 7.200% |
| 有效时长 `H` | 17 | 7 | 17 | 7 |
| `C` / `R` | 78.336% / 124.32% ✔ | 50.400% / 241.44% ✔ | 78.336% / 124.32% ✔ | 50.400% / 241.44% ✔ |

```text
干员经验（高级认知载体，单件基线 24.4444 h，每件 10,000 经验）
  A 班 24.4444 / 4.18 = 5.8480 h → 17 / 5.8480 = 2.9070 件
  B 班 24.4444 / 3.96 = 6.1728 h →  7 / 6.1728 = 1.1340 件
  日收割 = 4.0410 件 → 日经验 = 40,410（完成件数 floor = 4 件，只用于展示）

武器经验（武器检查套组，单件基线 9.7778 h）
  A 班 9.7778 / 4.18 = 2.3392 h → 17 / 2.3392 = 7.2674 件
  B 班 9.7778 / 3.52 = 2.7778 h →  7 / 2.7778 = 2.5200 件
  日收割 = 9.7874 件
```

> **两者不能比大小。** 干员经验件与武器经验件是不同物品、单件基线也不同，“`9.79 > 4.04`” 说明不了武器经验更值——选哪一类由全船**类别的字典序**决定（总规范 §6.1：线索 ≻ 干员经验 ≻ 武器经验 ≻ 培养），不由本表决定。
>
> 本表只回答：**本舱要跑某一类时，名单怎么配、产量是多少。**

## 4. 减免的价值门槛（避免红脸）

```text
避免红脸需要的减免 = 1 − 1/(0.072 × 班长)      # 班长 ≤ 13 时恒为 0
```

| 班长 | 需要减免 | 最低够用档位 | 心情消耗 | 有效时长上限 |
|---|---|---|---|---|
| ≤ 13 | 0 | 0% | 7.200% | 13.888889 h |
| 14 | 0.79% | 14%（昼雪/秋栗） | 6.192% | 16.149871 h |
| 16 | 13.19% | 14% | 6.192% | 16.149871 h |
| 17 | 18.30% | 28%（14+14） | 5.184% | 19.290123 h |
| 18 | 22.84% | 28%（14+14） | 5.184% | 19.290123 h |
| 19 | 26.90% | 28%（14+14） | 5.184% | 19.290123 h |
| 20 | 30.56% | 32%（18+14） | 4.896% | 20.424837 h |
| 21 | 33.86% | 36%（18+18） | 4.608% | 21.701389 h |
| 22 | 36.87% | 46%（18+14+14） | 3.888% | 25.720164 h |
| 23 | 39.61% | 46%（18+14+14） | 3.888% | 25.720164 h |

**但“够用”不等于“值得”。** 减免要占工位，占掉的就是加成位。制造舱的 18% 减免只挂在 4 个人身上（莱万汀、庄方宜、洁尔佩塔、骏卫），14% 只有昼雪、秋栗两人且**不带任何加成**。所以：

| 干员经验 A 班班组 | `b` | `r` | `E` | `1/d` | 不红脸能跑到的班长 |
|---|---|---|---|---|---|
| 莱万汀+庄方宜+余烬（或任意 3 个 30%） | 90% | 36% | **4.18** | 21.70 h | ≤ 21 h |
| 莱万汀+庄方宜+昼雪（或秋栗） | 60% | 50% | 3.52 | 27.78 h | ≤ 27 h |
| 莱万汀+昼雪+秋栗 | 30% | 46% | 2.86 | 25.72 h | ≤ 25 h |
| 余烬+卡缪+噗切娜（无减免可用） | 90% | 0% | 4.18 | 13.89 h | ≤ 13 h |

**所以 22 h 以上虽然“有档位够用”，却拿不到 90% 加成。** 该不该换？算一下 `h = 22`：

```text
保留 90%/36%、接受红脸（§4.4 长期值）
  W* = 24 × 17.76% / (4.608% + 17.76%) = 19.06 h
  长期值 = 4.18 × 19.06 + 2.2 × 2 = 79.65 + 4.40 = 84.05
换成 60%/50%
  C = 22 × 3.6% = 79.2%  vs  R = 2 h × 17.76% = 35.52%  ⇒ **照样不稳定**
  W* = 24 × 17.76% / (3.6% + 17.76%) = 19.96 h
  长期值 = 3.52 × 19.96 + 2.2 × 2 = 70.24 + 4.40 = 74.64
```

⇒ **别为了 22 h 去换减免**：换了只是把“班内红脸”推迟，却把倍率从 4.18 砍到 3.52，长期值反而低 9.4。这就是“减免的价值门槛”真正要说的事。

**读法**：17 h 只差 0.30 个百分点就能不红脸；20 h 要凑到 32%（18+14）；22 h 以上要 46%（18+14+14），三个工位全被心情占满——那时加成已经是 0。

## 5. 缺人与停产

| 场景 | 人数项 | 加成 | 倍率 | 相对满编 |
|---|---|---|---|---|
| 满编（三个 30%） | 2.2 | 90% | 4.18 | 100.0% |
| 换入 1 名纯心情干员（2 加成 + 1 心情） | 2.2 | 60% | 3.52 | **84.2%** |
| 缺 1 人、**且该组无人被单独补心情**（合并口径） | — | ≤ 60% | **0**（整舱停产） | 见 §5.1 |
| 缺 1 人、**但有人被助力补过心情**（分人口径） | 1.8 | ≤ 60% | ≤ 2.88 | **≤ 68.9%**（人数项 81.8% × 加成项 84.2%） |

90% 必须由三个 30% 加成位凑满，所以不存在「带着纯心情干员还有 90%」的班组。

**“少 1 人”不是只有一种结果**（总规范 §4.6）：

- **默认（合并口径）**：同班所有人共用 `d`，三人心情同步 ⇒ **同时红脸** ⇒ 整舱停产，产出 0。这时“人数项降到 1.8”根本不会出现，因为没人还在岗。
- **只有被助力打破同步之后**（只给其中 1–2 人补心情），才会出现“2 人在岗”的时段，此时倍率按 2.88 算。缺人表里那一行只在**分人口径**下成立。

**红脸离岗**：`h > 1/d` 的部分不计产出，但从红脸那一刻起人就离岗并按 `v` 恢复（总规范 §4.2）。例：`r = 0` 时 `1/d = 13.889 h`，若班长排 17 h，则 13.889 h 之后离岗休息 3.111 h——不是“留在岗位上空转”。

## 6. 边界

- **单班模式**（只放一组人，红脸后回满再战）：`周期 = 1/d + t满`，`日产出 = E·(1/d)·24/周期`（`E`、`d`、`t满` 见 §1/§2）。
  **周期不整除 24**，所以单班只保证长期平均，不保证每天相同（总规范 §5.2）。
- **什么时候才转单班**：只有在**第二组凑不出 3 个人**（连白板都没有）时才转。只要凑得出，两班一定比单班高——制造1 的算例：两班白板 `90.42` vs 单班 `76.65`。
- **生产载荷是点数，不是件数**：Lv3 = 480 点，`单次最多件数 = floor(480 ÷ 每件载荷)`。每件载荷由配方决定（表里“Lv3 单次最多”反过来就是它：初级 1、中级 2、R4 认知 5、R3/R4 高阶 12、R5 认知 30）。它只限制单次排产，**不影响速度**。
- 批次内不需要先领取才继续；整批跑完停在「可收取」。
- 切换配方无材料损耗，但会丢弃在制进度。
- 一律取技能最高档（γ，无 γ 则 β）。

## 8. 可选：助力（默认关闭）

> 制造舱**自己**的助力（+2,000,000 进度）不在本模型内。这里只算一种情况：中枢那 2 点心情点数**顺延**到本舱。

- 1 点 = 单干员 +30% 心情 ⇒ 多干 `30% ÷ 4.608% = 6.51 h`（36% 减免档）；32% 档则是 `30% ÷ 4.896% = 6.13 h`。
- **前提是本舱正在衰减**。本舱若已稳定（心情每天回满 100%），加点全部溢出作废，收益恒为 0。
- 顺延到本舱时，被补的那一班心情转**分人**（先红脸者先离岗，倍率按实际在岗人数重算），见 `帝江号排班与产出计算逻辑.md` §4.6。
- 本方案（制造1、制造2 都是 17 h / 7 h，中枢 14/10）：`R = 7 × 17.76% = 124.32% ≥ C = min(1, 17 × 5.904%) = 100%`，**已经稳定** ⇒ 顺延到本舱的收益为 0。
- **本舱自己的助力（+2,000,000 进度）不在本模型内**：它是固定的进度点数，`2,000,000 ÷ (360000 × E)` 小时——`E=4.18` 时 1.33 h、`E=2.20` 时 2.53 h。要算它就直接扣所需时长，与使用时刻无关。
