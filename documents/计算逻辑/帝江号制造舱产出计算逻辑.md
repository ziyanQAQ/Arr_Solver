# 帝江号制造舱产出计算逻辑

> 给定「在产配方 + 在岗干员 + 班长」，算出一个班次能收几件、多少经验。全船制造舱上限 2 间，本文按**单舱单班单配方**算。
> 心情闭环的通用口径见 `帝江号排班与产出计算逻辑.md` §4。

## 1. 变量

| 变量 | 含义 |
|---|---|
| 在岗人数 | Lv3 = 3 |
| 加成 | 在岗者中作用于**该 expType** 的生产效率之和 |
| 减免 | 在岗者中心情消耗降低之和 |
| 倍率 | 该班组的实际生产倍率 |
| 心情消耗 | 每人每小时心情消耗 |
| 班长 | 该班在岗小时数（整数） |
| 有效时长 | 真正在生产的时长 |
| 本班消耗 / 可回复 | 本班用掉的心情 / 休息期能回的心情 |
| 单件基线 | 100% 速度下一件的耗时 = `进度 / 360,000` |
| 收割次数 | 一个班次内能收几件（连续值） |
| 权重 | 玩家偏好，默认 1:1 |

**四条前提**

1. **一个舱一次只能产一种类型**：单产线串行，配方分干员经验 / 武器经验两类，所以同一间舱的产出永远是单一类别；要同时产两类只能用第二间舱。
2. **加成按 expType 隔离**：干员培养素材效能与武器培养素材效能是两条独立属性，产干员经验时吃不到武器经验加成。
3. **人数项是舱级的**：Lv3 = 2.2，另一类没被加成时也是 2.2。
4. **生产载荷不影响速度**：`machineCapacity` 只限制单次最多排几件，单件耗时公式里没有它。

| 等级 | 进驻人数上限 | 生产载荷 | 人数项 |
|---|---|---|---|
| Lv1 | 1 | 120 | 1.4 |
| Lv2 | 2 | 240 | 1.8 |
| Lv3 | 3 | 480 | **2.2** |

## 2. 算式

```text
加成      = Σ 该 expType 的生产效率提升
减免      = Σ 心情消耗降低
倍率      = (1 + 0.40 × 在岗人数) × (1 + 加成)
心情消耗  = 0.072 × (1 − 减免)
有效时长  = min(班长, 1 / 心情消耗)
本班消耗  = min(1, 心情消耗 × 班长)
可回复    = Σ 回复速度 × 休息时长
可行      = 可回复 ≥ 本班消耗

单件耗时  = 单件基线 / 倍率
收割次数  = 有效时长 / 单件耗时
完成件数  = floor(日收割次数)
日经验    = 10,000 × 日收割次数
```

**四个要点**

- **一个舱只有一类产出**：收割次数、完成件数、日经验都是单一类别的量，舱内不相加。
- **同一班组换配方，倍率会变**：干员向的班组产武器经验时 `加成 = 0`，倍率只剩 2.2。
- **取整放在日合计之后**：`floor(A 班 + B 班)`，不能两班各自取整再相加。
- **两类单件基线差 2.5 倍**：高级认知载体 24.44 h、武器检查套组 9.78 h（都是 10,000 经验/件）。

### 8 条配方的基础耗时（100% 速度）

| 配方 | 类别 | 稀有度 | 进度 | 单件基线 | Lv3 单次最多 |
|---|---|---|---|---|---|
| 初级作战记录 | 干员经验 | R1 | 92,000 | 15 分 20 秒 | 480 件 |
| 武器检查单元 | 武器经验 | R2 | 92,000 | 15 分 20 秒 | 480 件 |
| 中级作战记录 | 干员经验 | R2 | 420,000 | 1 小时 10 分 | 240 件 |
| 武器检查装置 | 武器经验 | R3 | 420,000 | 1 小时 10 分 | 240 件 |
| 初级认知载体 | 干员经验 | R4 | 1,050,000 | 2 小时 55 分 | 96 件 |
| 高级作战记录 | 干员经验 | R3 | 3,520,000 | 9 小时 46 分 40 秒 | 40 件 |
| **武器检查套组** | **武器经验** | R4 | 3,520,000 | **9 小时 46 分 40 秒** | 40 件 |
| **高级认知载体** | **干员经验** | **R5** | 8,800,000 | **24 小时 26 分 40 秒** | 16 件 |

> 默认取加粗两行（各自稀有度最高）。注意干员经验的 R5 认知载体与 R3 高级作战记录**经验值相同（10,000）而进度是 2.5 倍**——两者用途不同（作战记录对应 1–60 级、认知载体对应 61–90 级），不是高档替代低档。

## 3. 示例：同一舱的两个候选方案（二选一）

舱室 Lv3，A 班 17 h / B 班 7 h。A 班干员向、B 班武器向；下表把两种配方都算一遍以比较「该跑哪一类」，**实际只能选一个**。

| | A 班 | B 班 |
|---|---|---|
| 名单 | 莱万汀（干员 30、心情 18）+ 庄方宜（心情 18、干员 30）+ 余烬（干员 30） | 洁尔佩塔（武器 30、心情 18）+ 骏卫（武器 30、心情 18）+ 佩丽卡（武器 30） |
| 加成 干/武 | **90%** / 0 | 0 / **90%** |
| 减免 | 36% | 36% |
| 倍率 干/武 | **4.18** / 2.20 | 2.20 / **4.18** |
| 心情消耗 | 4.608% | 4.608% |
| 有效时长 | 17 | 7 |
| 本班消耗 / 可回复 | 0.78336 / 1.2432 ✔ | 0.32256 / 1.1760 ✔ |
| 单件耗时 高级认知载体 | `24.4444 / 4.18 = 5.8480 h` | `24.4444 / 2.20 = 11.1111 h` |
| 单件耗时 武器检查套组 | `9.7778 / 2.20 = 4.4444 h` | `9.7778 / 4.18 = 2.3392 h` |
| 收割次数 高级认知载体 | 2.9070 | 0.6300 |
| 收割次数 武器检查套组 | 3.8250 | 2.9925 |

```text
方案甲（整日只跑干员经验）
  日收割 = 2.9070 + 0.6300 = 3.5370 件 → 完成 3 件 → 日经验 35,370

方案乙（整日只跑武器经验）
  日收割 = 3.8250 + 2.9925 = 6.8175 件 → 完成 6 件 → 日经验 68,175

两者互斥，只能选一个。若第二间舱跑另一类：
  两舱合计 = 10.3545 件/日，日经验 103,545
```

> 两班倍率配置完全对称（各有一个 4.18、一个 2.20），但武器经验多出 **92.7%**——唯一原因是单件基线差 2.5 倍。若把干员经验换成高级作战记录（同为 3.52M），两类就完全对称。

## 4. 减免的价值门槛

```text
需要的减免 = 1 − 1/(0.072 × 班长)      # 班长 ≤ 13 时恒为 0
```

| 班长 | 需要的减免 | 最低够用档位 | 心情消耗 | 有效时长上限 |
|---|---|---|---|---|
| ≤ 13 | 0 | 0% | 7.200% | 13.888889 h |
| 14 | 0.79% | 14%（昼雪/秋栗） | 6.192% | 16.149871 h |
| 16 | 13.19% | 14% | 6.192% | 16.149871 h |
| 17 | 18.30% | 28%（14+14） | 5.184% | 19.290123 h |
| 18 | 22.84% | 28%（14+14） | 5.184% | 19.290123 h |
| 19 | 26.90% | 28%（14+14） | 5.184% | 19.290123 h |
| 20 | 30.56% | 32%（18+14） | 4.896% | 20.424837 h |
| 21 | 33.86% | 36%（18+18） | 4.608% | 21.701389 h |
| 22 | 36.87% | **46%（18+14+14）** | 3.888% | 25.720164 h |
| 23 | 39.61% | **46%（18+14+14）** | 3.888% | 25.720164 h |
| 24 | 42.13% | **46%（18+14+14）** | 3.888% | 25.720164 h |

> 制造舱有 **18% 与 14% 两档**，可用档位 `{14, 18, 28, 32, 36, 46, 50, 54}`（最多 3 人；14% 只有昼雪、秋栗）。

**读法**：班长 17 h 只差 0.30 个百分点；20 h 要凑到 32%（18+14）；22 h 以上要 46%（18+14+14），三个工位全被心情占满。

## 5. 缺人与停产

| 场景 | 人数项 | 加成 | 倍率 | 相对满编 |
|---|---|---|---|---|
| 满编（三个 30%） | 2.2 | 90% | 4.18 | 100.0% |
| 换入 1 名纯心情干员（2 加成 + 1 心情） | 2.2 | 60% | 3.52 | **84.2%** |
| 少 1 人（任何原因） | 1.8 | ≤ 60% | ≤ 2.88 | **≤ 68.9%**（人数项 81.8% × 加成项 84.2%） |

90% 必须由三个 30% 加成位凑满。停产等待：`班长 > 1/心情消耗` 的部分不计产出、不回心情。

## 6. 边界

- **单班模式**（只放一组人，红脸后回满再战）：`周期 = 1/d + 回满`，`日产出 = E·(1/d)·24/周期`，见排班文档 §5.2。
- 生产载荷只限制单次排产件数（Lv3：认知载体 16 件、武器套组 40 件），不影响速度。
- 批次内不需要先领取才继续；整批跑完停在「可收取」。
- 切换配方无材料损耗，但会丢弃在制进度。
- 一律取技能最高档（γ，无 γ 则 β）。
